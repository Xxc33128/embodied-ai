# 三项接口修复与首次模型视觉闭环

> v1.0，2026-09-15。承接《2026-09-15-robosuite适配器独立复核.md》的三项阻塞，按"修三项 → 同一工具接口完整抓放 → GLM 视觉试跑"收敛。E1=源码事实；E2=本轮实测；E3=本轮建议。

## 1. 三项修复（E1/E2）

| 问题 | 修复 | 回归把关 |
|---|---|---|
| 夹爪开合反向 | 协议 0=闭/1=开 → 底层 +1=闭/−1=开；**并按复核建议采用二值协议 + 滞回闩锁**（<0.35 闭、>0.65 开、中间保持）：move_to 省略 gripper 时目标=实测开度（夹持后 ~0.5），无滞回会在提升段被 0.5 阈值翻成张开（回归实测复现）。`ActionSemantics.gripper="binary"`，docs 披露 | 0→1→0 序列实测开度 0.01/0.99/0.01 同向 |
| yaw 四元数顺序 | `_yaw_from_quat_xyzw` 按 (x,y,z,w) 解析；eef_quat 对外统一转 wxyz 并 docs 声明 | +0.4/−0.4 rad 目标收敛 <0.1 rad；纯平移无漂移 |
| 相机看不到碗 | 碗壁补 group=1 视觉副本（contype/conaffinity=0 不加碰撞面）；离屏帧 OpenGL 上下颠倒 → `flipud` 后交付，docs 声明方向 | 三路 224² 均含碗体蓝色像素；front 视图碗位于下半幅（方向正确） |

其余收口：动作空间 z 下限 0.83→**0.80**（原下限挡住下探，是完整抓放 0/10 的直接原因——OSC 在 z≈0.85 被指尖触方块顶限速，需再降 ~1.5cm 才能包住方块）；成功判定统一用底层 `_check_success()`（含速度），`_phase` 用 `_check_grasp` 真实接触，info 增 `phase_max`（0–4 最高阶段评分数据源）；`reset(seed)` 重置噪声源（同 seed 轨迹逐步可重放，回归把关）；方块采样改为左半桌 x∈[−0.12,−0.04] + ±10° yaw，与 docs 一致。

## 2. 同一工具接口完整抓放（E2）

`test_robosuite_bowl_regression.py`：**13 项测试全绿**（原契约 8 + 新回归 5）。核心一项：**经真实 `build_toolset`/`move_to` 工具链的完整抓放 10/10**（seed 1000–1009，零噪声；悬停→下探→闭合→提升→搬运→下降→张开，闭合后仅移动不重指定开度）。三路相机可见性与 seed 重放各有专项测试。

## 3. GLM-5.3-flash 首次视觉闭环（E2：0/2，属调试结果）

`logs-rsbowl-glm-smoke/`（2 trials，350 步上限，20 次 LLM 调用预算，827s）：

- **闭环全链路工作**：模型每轮收到三相机图像+本体状态，notes 描述腕视内容并据此修正目标；夹爪二值语义使用正确（指令 0 闭合、1 张开）。
- **sample 0（max_steps）**：悬停→下探→一次在 z=0.97 过早闭合（高度误判，浪费预算）→ 重开再试，第二次下探闭合抬起后位置误判丢失方块，步数耗尽。
- **sample 1（give_up）**：接近→下探→微调→闭合 z≈0.83→抬起 0.96→**朝碗搬运（x 0.02→0.08→0.14，全程保持闭合）**——20 次调用预算在搬运途中耗尽，模型主动 give_up，距碗约 2cm。
- 初步判断（E3）：接口已不再是阻塞；剩余是模型侧调试空间——预算节奏（谨慎小步挪移消耗调用数）与闭合时机判断。可选的非协议手段：docs 强化闭合高度判据、或按口径讨论调用预算。
