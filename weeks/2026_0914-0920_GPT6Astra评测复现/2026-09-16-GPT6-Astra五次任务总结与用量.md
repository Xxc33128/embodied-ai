> v1.0 · 2026-09-16。统计范围：scene seeds **2000–2004 的五个有效 trial**。原计划为20次，目前仅完成5次；本文不把5/5外推为20/20。原始批次为 `logs-persistent-subagent20-20260915-113640/`。本报告为结论权威出处，数值与逐步记录在[结果目录](../../gpt6astra-repro/results/gpt-6-astra/)。
>
> 证据等级：E1为执行代码；E2为配置、原始日志与计数；E3为行为解释及引用其他报告的观察。本文“决策过程”指工具中已记录的观察、动作和简短理由及其事后验证，不包含内部思维链，也不补写未记录的心理过程。

## 1. 已完成什么

五轮的环境自动判据均返回成功，共 **61次机器人决策、2,161个控制步**。平均每轮12.2次决策，在20次预算内完成。五轮初始化与冻结库精确匹配，录像/请求/动作记录检查 **5/5 PASS**。[E2]

这不是五次一次抓准。第三、四轮首次抬手时方块仍留在桌上，模型发现后重新下降抓取；第五轮也识别了闭合位置过高并重新尝试。表现较好的共同点是能够依据后续观测纠正先前判断。[E2/E3]

**自动入碗成功与最终阶段审核分开报告。** 已完成的两份trial审核（01、02）确认了抓起、搬运、释放、进入碗内，但录像在着地后的反弹阶段结束，给出确定阶段3、可能上界4。trial01另有第二位独立复核者，结论相同。其余三轮尚未完成盲评，不能把五轮写成“盲评稳定放置5/5”，也不能把待定样本直接算成模型失败。[E2]

## 4. 可复核的决策过程

通常的动作顺序是：**观察相对位置 → 移动并校正方向 → 对齐下降 → 闭合 → 提升验证 → 搬运对齐 → 释放**。下面是日志支持的行为摘要，不是事后声称每一步都最优。[E2/E3]

| 可观察的做法 | 本批证据 | 作用与限制 |
|---|---|---|
| 用动作后的画面校正坐标方向 | trial05第1–4步：先沿x移动，再观察腕视变化并调整y | 方向判断可以逐步修正；并非一开始就获得准确物体坐标 |
| 看实测位置，不把目标当实测 | trial03第3步指出目标z=0.845而实测仍约0.932 | 识别控制器尚未走到目标，避免把已发指令当作已完成运动 |
| 闭合后试举验证 | trial03/04第7步提升后，第8步均指出方块留在桌上 | “半闭夹爪”只作为线索，最终用方块是否跟随验证 |
| 抓空后降低并重抓 | trial03第8–10步、trial04第8–10步 | 私有轨迹在第一次试举后grasped=false，第二次试举后grasped=true且物块离桌，证实重试有效 |
| 成功抓取后进行较大的目标移动 | trial03第11步、trial04第11步、trial05第11步 | 高层move_to交给现成控制器执行，减少搬运阶段决策轮数 |
| 对实际方块和碗口做释放前检查 | 各轮最后1–3步记录前视/侧视/腕视对齐情况 | 有助于避免只看末端目标；最终是否稳定仍要由评分侧验证 |

### 4.1 以trial03为例

1. 第1–5次决策：张开夹爪、下降、根据腕视调整横向位置及yaw；期间发现下探尚未到位。
2. 第6次：尝试闭合；第7次：试举。
3. 第8次：模型从图像发现方块仍在桌上，重新张开并降低到约z=0.805。
4. 第9次：原地闭合；第10次：再次提升。
5. 第11次：确认方块随手升高，开始搬向碗；私有核验显示此时方块底部z≈0.957，桌面z=0.8。
6. 第12次：对齐并降低；第13次：打开夹爪，随后环境自动终止为成功。

这些坐标是**该trial已经执行过的动作记录**，不是通用抓取答案，不应回填到后续模型测试提示中。模型运行时没有获得私有grasp/contact真值；它们仅用于本报告事后核验。

五轮全部61条工具说明原文、目标参数、控制步区间及等待时间见[公开决策记录](../../gpt6astra-repro/results/gpt-6-astra/decision-notes.md)；机器可读关联表见[decision-trace.csv](../../gpt6astra-repro/results/gpt-6-astra/decision-trace.csv)。

## 6. 中断与接入方式说明

- 每trial使用全新 `fork_turns=none` policy，整轮保持自己的观察和动作历史，不向下一轮传经验。trial04起由主agent直接管理policy。[E2]
- 标准任务、工具、20次决策/900步、0.25限速、三路224²图像保持一致。wire只带最近两组图像，但持久子agent保留曾见图像和工具运行上下文，因此单列persistent-subagent接入组，不称为独立API严格等价。[E1/E2]
- trial02首次尝试执行13个动作，等待第14次响应时因额度中断后超时；从同seed完整重跑，采用首个有效attempt。原尝试保留不计成绩。
- trial06只执行1个动作，等待第2次响应时中断，39个控制步后超时退出；**不是第六个有效trial，也不是模型任务失败**。
- 早期每决策创建新agent的试验按用户纠正作废，与本报告五轮分开保存。
- trial03的管理agent在环境已经完成后中断，最终文字通知未保存；13对原始请求/响应、轨迹和完整录像仍在，结束状态与成绩来自原始harness，不补造agent终报。
