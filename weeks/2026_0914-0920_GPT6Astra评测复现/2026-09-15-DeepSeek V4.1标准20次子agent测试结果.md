# 2026-09-15 DeepSeek V4.1 标准 20 次子 agent 测试结果（bowl-eval-v1 第二个完整模型批次）

> 证据口径：E2（本机实测运行记录）+ 项目规范选择 E3。结果仅代表该 20 场景冻结集 + persistent-subagent 接入组，不外推泛化，不与 Astra 真机 95% 直接比较。详细数据在 `gpt6astra-repro/logs-deepseekv4.1-subagent20-20260915-1435/`（RUN_STATUS.md / summary.csv / recording-audit.json / index.html）与本仓镜像 `gpt6astra-repro/results/deepseek-v4.1-flash/`。

## 结论速览

- **DeepSeek V4.1 在 bowl-eval-v1 标准 20 trial 上：审核成功率（盲评 stage=4）1/20，env_success 1/20，平均最高阶段 0.60。**
- 阶段分布：stage0 ×14、stage1 ×3、stage2 ×1、stage3 ×1、stage4 ×1。**唯一完成 trial-09（seed 2008）**：抓取 → 举升 → 持物至碗心正上方（6–9mm）→ 释放 → 静置于碗内（r≈8mm）；env_success 与两轮独立盲评一致。这是标准系列（GLM / DeepSeek 两批）里首个完整抓放入碗的 trial。
- 次优 trial-02（seed 2001）：夹举到 1.16m、持物经过碗口上方（块心距碗心最近 4.4cm，属边界），释放偏离 8.8cm 落至碗外壁——止步 stage 3（两轮盲评均判 3，附边界说明）。
- 记录质量：20/20 记录检查 PASS；初态与共享冻结库逐 trial 精确匹配；无预算越界、无推理期仿真推进、私有真值零泄漏（审计脚本自动核验）。

## 执行方式

- 依据《2026-09-15-bowl标准测试流程.md》与 `bowl-eval-v1/`：20 调用 / 900 步 / effort=medium（请求值）/ max_speed_frac=0.25 / image_horizon=2；提示词与物理逐 trial SHA256 校验。
- 每 trial 一个全新无历史子 agent 连续完成整 trial（persistent-subagent 接入组，与 GPT/GLM 同组定义与披露口径）。
- 共享冻结初态库（seeds 2000–2019，复制自 GPT 批次库，逐文件 diff 一致；aggregate SHA256 见 experiment.json）。
- 基础设施重试：trial-07 / trial-16 首跑因子 agent TLS 证书错误无效（分别停在决策 1 与决策 4），原 attempt 保留为 `trial-XX-infra-void-attempt1/` 并记录原因，按 SOP 以同一初态同一配置整 trial 重跑，采用 attempt 2；最终 20/20 有效（22 attempts）。
- 调度披露：先 5 路并发，后按用户要求补满至 15 路；推理等待期物理暂停、环境互相隔离、初态逐 trial 核对。**墙钟不作串行比较**（单 trial 1520–4334s 仅供参考）。

## 值得记录的现象（E2）

1. **盲评防幻觉再次有效（双向偏离）**：trial-01 模型自述“已夹住并提升”，盲评为 stage 1（仅推挪 2cm，`grasped` 全程 false、方块底高未离桌面）；trial-12 自述“方块位于指间、执行闭合”，盲评为 stage 0（全程无接触、方块位姿逐位不变）；反向地 trial-09 模型自述“无法确认是否入碗”，物理与两轮盲评均确认 stage 4。进一步支持 SOP §6“先评阶段、后看 notes”。
2. **执行时序怪癖被跨模型独立复现**：多个 trial 报告“位置型 move_to 仅执行 1–3 步；夹爪开合转变触发 ~79–80 步长窗口”，并被主动用于延长插值窗口——与 GLM 批次发现一致，属 SOP §4 预先披露的“重复指定 gripper 改变 chunk 长度”行为，协议内、全模型同工具。
3. **抓取建立是主瓶颈**：14/20 从未接触方块；3 个 stage 1 均为“推动/蹭到而非抓取”（夹爪闭合于方块旁 2–6cm 的空气，测距读数 0.016 全闭）。腕相机斜装 + eef 参考高于指垫导致 1–3cm 系统性对中偏差。
4. **释放精度是第二瓶颈**：进入 stage≥2 的 3 个 trial 无一干净入碗——trial-11 两次抓举但持物期离碗最近 0.19m；trial-02 越过碗口后释放偏出 8.8cm。
5. **预算行为**：调用均值 18.1/20（12 次 give_up、7 次步数耗尽、1 次 success）；14 个 stage0 trial 平均仍消耗约 18 次调用，探索成本高。

## 与 GLM 批次的配对对照（同库、同协议、同接入组，n=20）

- 配对 stage 差异：DeepSeek 更高 5 个 seed（01、02、09、11、16），GLM 更高 7 个 seed（03、07、08、15、17、19、20），8 个 seed 持平。
- 聚合几乎同分：平均最高阶段 GLM 0.65 vs DeepSeek 0.60；差异集中在“个别 trial 抓取建立成功与否”，两批的共同瓶颈（对中偏差、抓持稳定、释放精度）一致。
- 对照结论暂限定性：单批 20 场景、成功率低且方差大，不构成模型优劣判定。
