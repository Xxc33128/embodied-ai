# bowl 化与适配器：robosuite 路线的模型闭环打通

> v1.0，2026-09-14。承接《2026-09-14-后端核验-robosuite.md》，完成新口径 §4.1（bowl 化场景）与 §4.2（适配层）的主体工程。零付费 API；全部在隔离环境 `.venv-robosuite/` 运行。
> 证据口径：E1=源码事实；E2=本机运行复测；E3=本轮建议。

## 1. bowl 化（E2：脚本入碗 10/10）

自定义任务 `RoboBowl`（继承 robosuite Lift，仅重写场景装配与判定，控制全部走现成 OSC_POSE）：

- **碗体**：静态四壁轴对齐外倾 20° 漏斗（内口半径 ~4.9cm→顶部 ~7.7cm，壁高 6cm），直接 merge 进 arena，位置 (0.16, 0)。资产 `robosuite_bowl_asset.xml`。
- **成功判定**：方块中心水平距碗心 < 3.5cm 且低于碗口静置高、近静止。
- **独立脚本验证**：悬停→下探→闭合→提升→搬运→释放→撤爪→静置，10 seeds 全部入碗成功（~220 控制步/集 ≈ 11s 仿真，墙钟 ~2s/集）。

过程中排掉三个场景级坑（与 v3 机制存档呼应，已写进资产/脚本注释）：

1. robosuite 对象系统的 XML 约定（根 body 名 "main"、geom 需 group 属性、命名前缀）与静态布景不兼容 → 改为直接并入 arena；
2. **薄碗底与桌面共面叠层** → 方块穿底坐桌（-4mm 假接触）→ 删薄底，桌面即碗底（v3 同款方案）；
3. **竖直薄墙环会把方块卡死**（多面接触深 -2.4mm 摩擦自锁）→ 外倾漏斗壁下压即滑入。

## 2. 适配器（E2：契约 8/8 + harness 冒烟通过）

`robosuite_bowl.py::RobosuiteBowlEmbodiment`——纯协议翻译，零控制代码：

| inspect-robots 协议 | robosuite 侧 |
|---|---|
| `move_to` 绝对世界系 (x,y,z,yaw,gripper)，护栏已插值 ≤4cm/步 | OSC_POSE 世界系 delta（`input_ref_frame="world"`），按 `8·Δ` 归一化输入，控制器限幅 ±0.05m/步 @20Hz |
| gripper 0..1（0 闭 1 开） | ±1（**+1=闭，−1=开**，E0 标定）|
| 相机 front/side/wrist 224² | frontview / sideview / robot0_eye_in_hand |
| state：eef_pos/quat/yaw、eef_state(5)、**joint_pos/joint_vel/joint_eff(7)**、gripper 实测 | 对应 obs；joint_eff 取 qfrc_actuator（含重力/惯性补偿），对齐原评测观测口径 E2 |
| 物体真值 | **只进 info 供评分，不进模型观测**（契约测试把关）|

执行噪声默认 (0.0015, 0.001, 0.017)（与 v3 同参，作用于世界系 EEF 目标，米→归一化换算）。每 seed 重建环境保证 reset(seed) 可复现（~2s/次，20 trials 可接受）。

验证：

- `test_robosuite_bowl_contract.py` **8/8**：build_toolset 构建（state_key=eef_state、move_to、五维标签）、字段/量纲、真值不外泄、单维保持、插值限速、越界/缺 note 拒绝、done 终止、chunk 播放收敛（保持 15 步残差 <2cm）。
- `verify_robosuite_harness.py`（harness `eval()` 主链路 × 5 维悬停策略）：2 trials status=success、episode_length=60=max_steps、scorer/日志正常——接线层验证，悬停不解题故 success=0 为预期。
- 适配器单步实测：move_to 悬停目标 x/y 收敛至 ~1mm。

## 3. 环境与入口（E2）

- 全部在 `.venv-robosuite/` 运行：robosuite 1.5.2 + robosuite-models 1.0.0 + mujoco 3.3.0 + inspect-robots 0.58.0 + inspect-robots-agent 0.26.0（numpy 1.26.4 两栈兼容；主 venv 未动——robosuite 子依赖要求 numpy<2，与主 venv numpy 2.4.6 冲突，故反向隔离）。
