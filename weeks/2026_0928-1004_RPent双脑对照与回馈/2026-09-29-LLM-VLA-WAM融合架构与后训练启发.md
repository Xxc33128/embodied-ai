# 从 LIBERO 记录看 LLM、VLA、WAM 的融合架构与后训练

版本：v1.0 · 日期：2026-09-29

三位子 agent 分别从架构、性能、纠错与实验设计出发，随后交叉审查。本篇汇总共识、修订与待验证方案。没有启动新实验、模型请求或训练。这里将用户的“val”按 VLA 理解；WAM 指本方案中具备动作条件后果预测能力的世界／动作模型分支，不特指已经部署的某个模型。

**核心判断：当前最值得研究的是如何以较低成本获得可靠的目标判断、动作后果预测和持续恢复，而不是每一步都让三个模型串行参与。**〔E3／方案判断〕

本批只有三个任务、三条路线、各一个 init 0，共九回合。没有 WAM 实测、没有后训练对照，不能据此宣称三模型融合或某种训练方法已能提升成功率。〔E2〕以下以〔E1〕标示既有源码或记录，〔E2〕标示配置，〔E3〕标示解释、敏感性估算与研究方案。

## 1. 哪些实测现象最有架构意义

| 报告事实〔E1〕 | 提示的研究问题〔E3〕 |
|---|---|
| Hybrid 每轮约 18.8–22.4 s，通常只推进 0.25 s 仿真；等待模型时物理暂停 | LLM 应在什么时间尺度介入？真实环境持续变化时，旧决定还能否执行？ |
| Hybrid 的 GPT 往返占整轮 76%–82%，π 推理与同步仅 2.3%–2.8% | 瓶颈主要在决策交付链，单独优化 VLA 内核未必改善闭环 |
| Hybrid 162 次审核中149次放行，13次接管；罐子和微波炉102次全部放行 | 每次审核的信息价值是否值得等待？怎样减少低价值调用而不漏检？ |
| 抽屉13次接管均让末端产生动作，平均实际移动33.92 mm；底层抽屉却始终没动 | 几何纠偏不等于语义纠错；恢复应以正确部件的实际进展为目标 |
| gate 提示仍要求根据 FK 轨迹判断意图，LIBERO 实际提供归一化动作数组 | 审核输入是否能支持要求它完成的判断？先修接口再归因模型能力 |
| Hybrid 可见输出约330 Token、Decode约9.3–9.6 s；控制字段出现后仍等8.4–8.7 s | 控制消息与冗长说明是否需要在同一关键路径上？ |

这些现象支持提出问题，不构成因果证明。特别是 FK 表征缺口不能直接解释为抽屉失败原因，全放行也不能证明审核无用。〔E3〕

## 2. 架构：先明确三类模型各自贡献什么

建议以“LLM + VLA + 确定性校验”作为轻量对照，再评估加入 WAM 的增量价值。以下是目标架构，不是当前实现。〔E3〕

| 层 | 主要职责 | 输入与输出契约 |
|---|---|---|
| LLM：语义与恢复决策 | 确认任务、对象和部件；分解子目标；判断异常与交还条件 | 接收允许的视觉与状态、候选动作及预测摘要；输出目标引用、阶段、约束和经校验可执行的决定 |
| VLA：动作候选与局部执行 | 在明确任务／子目标下生成短动作序列 | 输出动作坐标系、单位、有效范围清楚的 action chunk；是否支持子目标条件化需单独验证 |
| WAM：动作条件后果预测 | 估计有限候选的短时后果，辅助判断对象与子目标进展 | 输入当前观测／状态和候选动作；输出预测对象变化、进展、风险及经验证的不确定性表征 |
| 本地主机／控制器 | 限幅、消息完整性、版本／过期检查、执行和观测反馈 | 始终保留独立校验；模型自评或预测不能绕过动作边界 |

### 2.1 WAM 首先回答与任务有关的问题

抽屉场景中，可比较的预测是：“候选 A 将拉动中层；候选 B 只是脱离接触；候选 C 有望接近底层把手。”这类预测是否准确，需用后续真实观测验证。高层的目标身份本身若认错，WAM 即使正确预测了中层运动，也不一定知道这违反任务，因此目标语义与动作后果必须联合检查。〔E3〕

当目标不可辨、预测低可信或与实际观测冲突时，回退重新观测／原审核，而不是据此放行动作。主动观察或保持还需要实际控制接口支持，不能只写在提示里。〔E3〕

先比较短时对象／关系预测、轻量进展判别器、控制器感知的机器人运动摘要与较重的 WAM。只有需要时才测试高分辨率未来视频。不同表征的成本和判别质量都未知；不能预设 WAM 天然更准确，也不能把归一化动作直接求和当成米制未来轨迹。〔E3〕

### 2.2 调度比简单串联更重要

拟议流程：先确认目标与子目标，由 VLA 给出候选；常规阶段使用本地校验与受限执行。首次关键接触、闭爪／释放、阶段变化、持续无进展、预测与实测偏离时，触发额外预测或 LLM 审核，并保留周期抽查。不能只按动作平稳或 VLA 自信跳过语义审核，错对象动作也可能很流畅。〔E3〕

每个决定绑定观测版本、采集时间、候选版本和可执行条件。LLM 或 WAM 结果到达后，主机验证它是否仍适用于当前状态。允许的过期范围和失配处理需要测定；当前暂停式仿真不能验证真实异步控制。异步实验应让环境持续推进，并注入实测时延。〔E3〕

### 2.3 把恢复作为有结束条件的子任务

抽屉第一次接管出现在第125／300控制步，之前已花556.75 s；这说明大量预算已消耗，但未标注“首次视觉可识别错误”的时点，不能把125步全部称为漏检延迟。〔E1/E3〕

建议显式区分正常、目标存疑、确认、恢复、验证和交还。恢复验证至少区分：正确部件是否重新可见并被确认、机器人是否脱阻稳定、交还后的短窗口是否继续朝同一子目标推进。脱阻不等于后两项成立。窗口和阈值应在对照前确定；不能让模型再输出一次 recovered 就作为成功标签。〔E3〕

## 3. 后训练：分别训练诊断、执行与预测

### 3.1 数据单位从“漂亮回复”变为“状态—决定—结果”

建议样本保存任务／子目标、允许输入的图像与 proprio、历史摘要版本、VLA 候选、实际采用动作、各阶段时延，以及后续实际对象变化和原生结果。标签要区分“目标识别正确”“应该介入”“动作执行到位”“任务有进展”“恢复并稳定交还”。〔E3〕

GPT 的 reason、assessment 和 recovered 是模型自述，不能直接充当正确标签。当前抽屉13次接管均未完成底层任务，适合难例分析，不能标作成功恢复示范。九回合也不足以支撑可靠的后训练收益结论。〔E1/E3〕

| 模块 | 可以后训练什么〔E3〕 | 需要补齐的数据与检验 |
|---|---|---|
| LLM／可训练审核器 | 目标部件确认、失败识别、何时审核／接管／交还、紧凑决定格式 | 独立标注的正确与错误放行、过早交还、未知／遮挡样本；不能只模仿原审核结果 |
| VLA | 明确子目标下的恢复技能、纠正后继续完成任务 | 同类失败状态下成功恢复与失败尝试，覆盖重新观察、脱阻、重定位、接触、操作和交还 |
| WAM／后果模型 | 候选动作对对象、接触和短期进展的预测 | 实际执行的状态转移、同状态不同动作的分叉结果、分布外和预测失败样本；单独测误差与不确定性校准 |
| 调度／路由器 | 何时值得付出额外模型调用成本 | 调用与不调用的配对结果或受控干预；只看历史调用日志难以得到未调用的真实后果 |

若当前闭源 LLM 不支持所需后训练，就把它用作候选标签或解释的提供者，经核验后训练可训练的审核器／路由器；不要把 prompt 改写的结果写成“LLM 已完成后训练”。〔E3〕

### 3.2 需要补的是分叉恢复数据

从接近错误把手、已经接触错层、脱阻后准备交还等状态出发，对照继续原策略、先观察、修改目标、持续恢复等处理，并记录真实后续结果。必须保存足以恢复模拟器、控制器与策略随机状态的信息，仅拷贝 qpos 不足以保证同状态对照。〔E3〕

现有 π 预测10步、通常只执行前5步。未执行后缀没有真实后果标签；不能把原轨迹后续五步误当作该后缀的结果，也不能在干预已改变状态后继续复用旧候选来冒充在线反事实。〔E1/E3〕

仿真对象真值可用于独立评分，或在明确声明下生成训练标签；部署侧策略输入仍限制为任务允许的图像与 proprio。应记录真值的使用位置，防止训练／测试泄露。测试集按初态、场景或任务划分，避免相邻帧随机拆分造成近重复泄露。〔E3〕

### 3.3 训练目标兼顾效果与代价

可探索“任务／子目标进展 − 错误对象操作代价 − 时间和模型调用成本”的目标，但先把最低成功水平、漏检和动作约束作为明确验收条件，再比较成本。否则模型可能通过少调用、早停、声明完成，或迎合 WAM 的错误评分获取表面收益。权重需要实验选择，本报告不提供已验证值。〔E3〕

WAM 生成的想象转移应与真实采样分开计数；增加合成样本数并不等于获得同量真实证据。〔E3〕

WAM 评分是预测代理，不能同时充当唯一训练奖励和唯一验收标准。最终仍以独立真实环境回放和原生结果检验；预测驱动的候选优化越强，越需要检查是否利用了世界模型误差。〔E3〕

## 4. 推理性能：先优化闭环的关键路径

### 4.1 紧凑输出的目标是更早拿到完整、有效的决定

优先试验按模式裁剪 JSON：保留观测／请求身份、目标部件、子目标、状态判断和该 mode 必要参数；删除未启用分支与反复展开的长清单。关键失败／不确定证据保留短字段。长解释可另做审计，但必须标为后处理，不能冒充决策当时的输出。〔E3〕

交叉审查否定了“只留 mode 和 steps”的过度精简方案：更短也可能只是更快误放行。原长输出中控制字段虽已出现，仍不能执行半截 JSON，实际日志已有废弃流后重发的事件。〔E1/E3〕

### 4.2 新增 WAM 必须算净收益

在同等任务质量与风险约束下，比较：

```text
净节省 = 减少的 LLM 等待 + 减少的失败／恢复耗时
         − 新增 WAM、表征转换、同步和重验证的关键路径耗时
```

这是对照实验的分析式，不是现有实测。重叠计算应按完整时间轴去重，不能把每个模型耗时简单相加；被丢弃的过期预测、重算与资源争用仍要计入。先用少量候选、较短预测范围和按需触发，再测是否值得扩大。〔E3〕

视觉编码／latent 复用需接口兼容和误差验证。可先复用同帧采集、缩放和不可变快照。三个模型看同一张图，不代表其内部表征可直接共享；若需要适配器，其训练与运行开销也属于成本。〔E3〕

### 4.3 三种“快”分别统计

| 目标 | 主要指标与限制〔E3〕 |
|---|---|
| 单回合闭环延迟 | 完整有效决定的 p50/p95、观测年龄、过期结果执行率、固定墙钟预算内完成情况 |
| 多回合评测吞吐 | 单位时间完成回合数、设备利用率、队列等待；多卡并行不自动缩短单回合依赖链 |
| 后训练采样吞吐 | 单位时间获得的有效状态转移、成功恢复／可分辨分叉样本；包括重置、渲染、保存和队列排空 |

Hybrid 中 π 推理耗时减半仅对应约1.011–1.014倍整轮速度；纯 π 的渲染与保存占75%–80%，优化采样平台可能比优化策略内核更有效。这是固定其他条件的敏感性估算，不是已实现提速。〔E1/E3〕

已有缓存对比中，罐子前后12轮平均输入从21,494增至67,806.5，TTFT只从4.38 s变为4.90 s，Decode约9.6 s。可先保持稳定前缀，减少冗长输出，再对历史管理做隔离对照；不能把 TTFT 当作纯 Prefill。新增“含推理 TPOT”只对同一 Decode 时间换分母，也不能用它衡量隐藏推理速度。〔E1/E3〕

## 5. 建议的最小实验阶梯

以下是待选择方案，不是已获授权启动的实验；每一步保留旧版本对照，不同时改变全部模块。〔E3〕

1. **先校正接口并定位错误。** 固定关键帧与候选，对比原 gate、仅修正 FK 术语、再增加经验证运动摘要。标注对象／部件和可观察错误起点，评价诊断质量；不以原 GPT 判断作为唯一答案。
2. **独立验证短输出。** 在固定协议语义和输入下比较完整与紧凑 Schema，测完整响应延迟、目标／失败识别、误放行和校验失败。不能同时修改 FK 表征，以免失去归因。
3. **补恢复数据，做单模块后训练。** 以抽屉难例为起点补分叉正负样本；先分别训练审核器或 VLA 恢复技能，再在配对多初态上看恢复和交还后的再失败。
4. **检验 WAM 增量价值。** 轻量基线与增加 WAM 预测筛选对照；评价对象后果预测、误否决／误放行、预测净成本和固定墙钟完成情况。离线预测更准不等于在线纠错更强。
5. **最后联合优化调度。** 在模块质量可接受后试事件审核、WAM触发和异步。让环境持续推进，以观测过期、漏检和完成率约束提速；并发吞吐另行报告。

### 5.1 一个可缩放的试点预算

子 agent 提出的诊断起点是：12个关键状态×当前图／原历史×原／修正提示×2重复，共96次请求；随后从6个可完整恢复的状态，各试原π、目标条件π和恢复候选，再配2个随机种子，共36条短分叉。上述数量只是便于控制成本的设计，不是统计功效计算，也未执行。固定帧请求只回答识别和接口问题；36条分叉只能筛查恢复路径，不足以声称训练收敛。没有成功恢复正例时，先补可靠示范。〔E3〕

闭环可从5个独立留出初态×2种子×3个已明确的对照配置开始，共30回合；这是试点，不是总体成功率承诺。若要估计稳定收益，应根据结果方差与期望差异扩大样本。罐子与微波炉还需作为保持集，检查改进抽屉是否引入误干预。〔E3〕

## 6. 交叉讨论后保留的分歧与边界

- **LLM 是否应该每轮审核：** 认为成本值得优化，但没有证据可直接删除全放行轮。需要目标确认、关键事件与周期抽查的联合对照。
- **精简输出是否损害诊断：** 从仅保留控制字段修订为保留最小诊断证据的条件 Schema；效果未知。
- **WAM 是否有必要：** 架构上有潜力补动作后果表征，但先与轻量预测／判别基线比较，不能因新增模型就假定收益。
- **接口不匹配是否导致失败：** 不匹配是已核对事实，致因仍需单变量实验。
- **恢复如何结束：** 不接受模型自述作为唯一交还条件；需要允许观测中的目标、稳定状态和交还后进展验证。所需窗口尚未确定。

以上分歧都是下一步实验问题，不能在总结中写成已实现结论。〔E3〕
