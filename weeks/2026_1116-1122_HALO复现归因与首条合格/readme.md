# 2026-11-16 ~ 11-22 HALO 复现归因与首条合格

主线是 Apple HALO 的复现：从 Phase 0 冒烟起步，首批 30 集一条都不合格，逐步归因到去噪步数预算，修掉之后拿到首条合格轨迹，再往后推进数据链、回放评估与四周执行包。HomeBody 侧本周只推进了一小步。本目录各文档于 **2026-11-23** 补录入库；整理时只做脱敏与归位，未重跑任何实验。

## 本周目标

- HALO：在现有资源上跑通 **SIT 数据生成 → generator 训练 → tracker 训练 → MuJoCo 坐下闭环**（执行计划 v2 的目标）。资源分工是 NPU 节点跑 datagen 全链与 generator 训练／推理，T4 节点跑 tracker 全阶段训练与 ONNX 导出。
- HomeBody：把 VLM×SONIC 实验分支的架构写成文档，并用离线探针验证"单次引导抽样"能否赶上发布截止时间。
