## 5. R5-1：固定指标定义

### 5.1 四个条件

```text
I00 = Isaac D00
I20 = Isaac D20
M00 = MuJoCo elbow-matched D00
M20 = MuJoCo elbow-matched D20
```

所有比较均使用相同的 500 个 control cycles，按 `policy_step` 一一配对。不得通过插值或截断隐藏周期不一致。

### 5.2 D20 对 D00 的轨迹敏感度

对每个引擎计算：

```text
q_sensitivity = sqrt(mean((q_D20 - q_D00)^2))
q_des_sensitivity = sqrt(mean((q_des_requested_D20 - q_des_D00)^2))
```

术语使用 `trajectory sensitivity`。没有预注册工程阈值时，不输出 delay robustness PASS/FAIL。

关节分组必须固定为：

```text
LEGS  = 12 个 hip/knee/ankle joints
WAIST = waist_yaw_joint、waist_roll_joint、waist_pitch_joint，共 3 个
ARMS  = shoulder/arm_yaw/elbow/wrist joints，共 14 个
```

脚本应在 JSON 中输出每组的 joint names 和 indices，组大小必须为 `12/3/14`，并断言三组不重叠且覆盖全部 29 关节。

### 5.3 requested 和 effective tracking

分别计算：

```text
requested_tracking_rms = RMS(q_des_requested - q)
effective_tracking_rms = RMS(q_des_effective - q)
```

D00 没有显式延迟字段时：

```text
q_des_requested_D00 = q_des
q_des_effective_D00 = actual_processed_q_target（若与 q_des 逐点一致）
```

若两者不逐点一致，脚本必须停止，禁止自行替换字段。

### 5.4 body 和 root 指标必须拆成两套

当前已有预期值使用 world-frame `actual_body_pos_w`。R5 需要同时计算：

1. `body_position_world_rms`：14-body 世界坐标差；
2. `body_position_pelvis_relative_rms`：每一帧先减去 pelvis 位置，再比较身体相对构型；
3. `root/pelvis_position_rms`：单独表示整体平移；
4. body 和 pelvis orientation geodesic；
5. body linear/angular velocity RMS。

四元数角度统一使用：

```text
theta = 2 * acos(clip(abs(dot(q1_normalized, q2_normalized)), 0, 1))
orientation_rms = sqrt(mean(theta^2))
```

禁止把四元数四个分量的普通 RMSE 标为 orientation error。

这项拆分会影响解释。初步复算显示：

```text
cross-engine world body position gap: 0.104610 → 0.074709 m，下降约 28.6%
cross-engine pelvis-relative body gap: 0.017400 → 0.023317 m，上升约 34.0%
cross-engine pelvis position gap:       0.103292 → 0.070367 m
```

世界坐标 body gap 的下降主要与 pelvis/root 平移更接近有关，身体相对构型并未同步改善。R5 图表和结论必须同时呈现这两层，避免把 world position 的下降概括为整体 Sim2Sim 一致性改善。

### 5.5 其他必算指标

```text
survival time、cycles、fall_reason、reset_count
root height、x/y drift、roll、pitch
14-body position/orientation/linear velocity/angular velocity
pelvis/feet/hands anchor position/orientation
Isaac–MuJoCo cross-engine gap：D00 与 D20
MuJoCo applied_policy torque：RMS、peak、饱和比例
MuJoCo qfrc_actuator_policy：作为补充，不与 applied_policy 混称
Isaac torque：UNAVAILABLE
action 与 q_des variation
```

所有指标在 `p3_metric_schema.json` 中写明：字段来源、公式、单位、聚合维度、坐标系、是否为主指标。

```text
跨引擎 q gap 和 body orientation gap 增加；world-frame body position gap 下降主要来自 pelvis/root 平移更接近，pelvis-relative body gap 同时增加。
这些结果表明不同指标呈现 tradeoff，不能用单一 world position 指标概括 Sim2Sim 一致性。
```

不得外推到全部动作、全部 delay 值、Isaac 原生 DelayBuffer 或其他模型资产。
