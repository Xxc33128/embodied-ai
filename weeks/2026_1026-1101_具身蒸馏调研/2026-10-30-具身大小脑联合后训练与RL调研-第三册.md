## 0. 三句话结论（第三册视角）

1. **四路全网检索支持并加强 v1.0 的判断**：「独立大小脑双端、同一任务奖励、双侧策略梯度的成熟公开配方」截至 2026-10 仍不存在；公开最接近的是三档替身——**TEMPO**（语义-动作解耦、双时间尺度 RL）、**Z-1**（selective joint training 开关）、**π\*0.6 RECAP**（端到端但 Knowledge Insulation stop-gradient）。〔E3，四路检索判断，非空白断言〕
2. **产业界零公开**：Figure（Helix/Helix 02/Helix 2.5）、智元（GO-2）、Galbot（AstraBrain）、NVIDIA（GR00T N1.7/N2）、Skild 的 2026 年公开材料均不含联合 RL 训练细节；PI 的 π\*0.6（整体离线 RL）与 RLT（冻结大脑只 RL 附加小模块）是仅有的两档公开姿态。〔E3〕
3. **第四条消解路线正在成为主流叙事**：NVIDIA 把产品线转向 World Action Model 大一统（DreamZero→GR00T N2、Cosmos 3），把"两侧联合 RL"问题转化为"单一 video-action 生成模型的 RL 后训练"——这条线目前同样只有 SFT 式后训练，RL 空白与双系统路线相同。〔E3〕

## 3. 新增线 A：双系统联合 SFT 谱系与工程教训

v1.0 聚焦 RL，本册补齐"联合 SFT 怎么做才不崩"的实证基础——它是联合 RL 之前的必要热身。

### 3.1 接口谱系三支点（2024）〔E3，转述级〕

[LCB](https://arxiv.org/abs/2405.04798)（latent code token 桥）、[DP-VLA](https://arxiv.org/abs/2410.15549)（VLA 末层 hidden embedding，S2 全冻）、[HiRT](https://arxiv.org/abs/2410.05273)（pooled feature + 策略微调）——构成 latent token／hidden state／pooled feature 三种接口基线。[RoboDual](https://arxiv.org/abs/2410.08001)（2024-10）[已核] 是该谱系最完整配方：先 LoRA 微调 generalist 再**冻结**，从头训 20M specialist；双通路接口（离散 action token 拼接 + latent 经 cross-attention 进 DiT）；CALVIN ABC→D 54.4%，真机 ALOHA +26.7% vs OpenVLA。**无 RL。**

### 3.2 工业双系统联合训练的公开细节

| 系统 | 联合训练方式 | 关键工程点 | 证据 |
|---|---|---|---|
| [Helix](https://www.figure.ai/news/helix)（Figure，2025-02） | **端到端联合 SFT**：单一回归 loss，梯度从 S1（80M，200Hz）经 latent 回传 S2（7B VLM，7–9Hz） | S2 蒸馏为单一连续 latent 向量；训练时加 S1/S2 输入时间偏移以对齐部署异步；VLM 自动 hindsight 标注 | E3（官方博客已核） |
| [Helix 02](https://www.figure.ai/news/helix-02)（2026-01） | 三层：S2/S1 延续端到端 SFT；**System 0（10M @1kHz）用 sim-to-real RL**（20 万+并行环境、domain randomization） | RL 只放最低频控制层；4 分钟全自动洗碗机装载（61 个连续动作） | E3 |
| [GR00T N1](https://arxiv.org/abs/2503.14734)（NVIDIA，2025-03） | 三阶段：VLM 网络预训练→数据金字塔端到端 pretraining（5 万 H100 时、batch 16384）→post-training SFT 冻结语言组件、视觉编码器与 DiT 联合微调 | cross-attention 取 VLM **第 12 层**（非末层）token；LAPA latent action 伪标注把人类视频变成中间层训练数据 | E3（HTML 全文） |
| [GR00T N1.5](https://research.nvidia.com/labs/gear/gr00t-n1_5/)（2025-06） | VLM **全程冻结**（比 N1 更保守）＋ FLARE loss（预测未来潜表征而非生成未来帧） | Language Table 93.2% vs 52.8%；"未来预测监督"以潜空间对齐形式进入双系统 SFT | E3 |
| [π0.5](https://arxiv.org/abs/2504.16054)（PI，2025-04） | 两阶段全参 SFT co-training；**高层 subtask／边界框语义预测与低层 action 同一 loss**（数据集级协同） | 网络与语义数据占 97.6%；action expert post-training 时随机重初始化加入，flow loss α=10 | E3 |
| [GO-2](https://www.agibot.com)（智元，2026-04） | 异步双系统＋**动作思维链**（先在动作空间生成高层动作序列规划再执行）；细节未公开 | CVPR/ACL 2026 接收（论文本体未上 arXiv） | E3（多源转述） |
| [DuoCore-FS](https://arxiv.org/abs/2512.20188)（2025-12）／[Fast-in-Slow](https://arxiv.org/abs/2506.01953)（2025-06） | 前者真异步快慢双通路；后者把 System 1 嵌进 System 2 权重内（嵌套式，省一份部署） | 均为架构工程样本 | E3 |

### 3.3 OpenHelix：联合训练可行性边界的实证地图〔E3，HTML 全文已核〕

[OpenHelix](https://arxiv.org/abs/2505.03912)（2025-05）对"联合训练怎么才能不崩"给出目前最系统的消融，四条结论对联合 RL 前置设计直接适用：

1. MLLM latent token 默认只编码指令语义、对视觉不敏感（"退化为 LLM"），**必须加辅助 action-prediction loss 强制视觉 grounding**；
2. 最优训练策略是 prompt tuning + 预训练 policy 微调的保守组合；
3. **先 projector 预对齐再联合训练，否则联合训练直接崩溃（0% 成功）**——这是"全参联合 RL 无先例"现象在 SFT 层面的镜像；
4. 大脑低频推理（60 步一次）几乎不掉分——"异步"可能是伪需求。

## 4. 新增线 B：flow／diffusion 动作头 RL 的方法栈完备化

v1.0 §3.2 已核 π_RL 主结论；本册补全方法栈与"RL 小附件"路线。

### 4.1 log-likelihood 不可解的两族解法

| 方法 | 机制 | 出处 |
|---|---|---|
| Flow-Noise | 加可学习噪声网络，把每个去噪步变成高斯转移，整条去噪序列似然精确可算，标准 policy gradient 直接可用（训完丢弃噪声网） | [π_RL](https://arxiv.org/abs/2510.25889)（2510.25889，v3 2026-01）[已核]；[ReinFlow](https://arxiv.org/abs/2505.22094)（清华，2025-05，独立收敛）[转述] |
| ODE→SDE | score–velocity 关系把确定性 ODE 换成保边缘分布的 SDE，构成"内层去噪 MDP 嵌套外层环境 MDP"两层 MDP；ODE/SDE 混合 rollout 约 2× 加速 | [π_RL]；[Flow-GRPO](https://arxiv.org/abs/2505.05470)（文生图起源，NeurIPS 2025；**已被搬进 VLA**：Z-1、Prophet/FlowScale）[已核 ID／转述] |
| 去噪 MDP 视角 | 把每个去噪步当 MDP 的一步跑 PPO（理论底座） | [DPPO](https://arxiv.org/abs/2409.00588)（2024-09）、[ADPO](https://arxiv.org/abs/2505.08376) [转述] |

**π_RL 的负面发现**（对纯任务奖励 RL 直接适用）〔E3，HTML 已核〕：主算法 **PPO(GAE) 优于 GRPO**（π0 LIBERO 平均 96.0 vs 90.0）；去噪步 K=1 会训崩；**动作块越大 RL 上限反而越低**；噪声幅度 a=0.5–0.8 最佳；LoRA 解冻 VLM（r=32, α=32）在 LIBERO 上调整后仅与冻结组相当（与 v1.0 §3.2 一致）。

### 4.2 不走 policy gradient 的替代路线

- **π\*0.6 RECAP**（[2511.14759](https://arxiv.org/abs/2511.14759)，2025-11）[已核]：迭代式**离线 RL**——distributional value function（201 bins 预测归一化负 steps-to-success）→ advantage 二值化为文本前缀条件（推理时固定正优势 + CFG）→ 人类纠正动作强制标正优势。端到端训练但 **Knowledge Insulation stop-gradient**（flow loss 不回传 VLM；[KI 博客](https://www.pi.website/research/knowledge_insulation)：裸加 action expert 毁掉 web 知识，全冻学不会控制，KI 比 π0 少 7.5× 训练步）；value 用独立 670M 骨干混 web 数据防过拟合。
- **RLT（RL tokens）**（[pi.website/research/rlt](https://www.pi.website/research/rlt)，2026-03）[已核]：冻结 π0.6，旁路信息瓶颈式 RL token，小 actor+critic 做 off-policy RL，对 VLA 动作**编辑而非替换**；15 分钟真机数据适配。PI 2026 姿态＝冻结大脑只 RL 小附件。
- **FlowPRO/RPRO**（[2606.05468](https://www.alphaxiv.org/abs/2606.05468)，Tencent Robotics X，2026-06）[转述]：无 reward 函数，遥操作"干预-回滚"造 chosen/rejected 轨迹对，冻结参考策略的 flow 回归损失差定义隐式奖励；去掉 proximal 正则（≈裸 DPO）隐式奖励漂到 ~10²、性能崩塌。
- **EXPO 系**（Stanford）：[EXPO-FT](https://arxiv.org/abs/2605.25477)（offline 初始化＋在线 RL 稳定化，真机三任务 30/30，平均 19.1 分钟在线数据）、[Real-Time EXPO-FT](https://arxiv.org/abs/2609.18207)（2026-09）[已核]：大 VLA 只出动作块提案、轻量 **edit policy** 在最新观测上快速修正，只 RL edit policy；动态真机任务 42%→97%（10 分钟在线数据）。

## 5. 新增线 C：GRPO 退化与 credit assignment 的 2026 变体

纯任务（二元）奖励下 GRPO 的两个结构性问题及解法，对 LIBERO-Long 式长程任务直接对口：

| 问题 | 工作 | 解法 | 结果 | 证据 |
|---|---|---|---|---|
| 二元奖励下 all-success／all-failure 组零优势被 dynamic sampling 丢弃（训练早期大量浪费） | [Prism-GRPO](https://arxiv.org/abs/2608.17423)（2026-08） | 叠加轨迹级**执行质量分**（仿真接触／动作平滑度／VLM 信号），把同结局组在质量谱上再分裂；成功仍恒优于失败 | RoboTwin 达目标成功率省 56% rollout；压制一种 reward hacking | E3 |
| trajectory-level credit aliasing（中途正确但最终失败的 rollout 错误惩罚早期动作） | [Temporal GRPO](https://arxiv.org/abs/2608.13026)（2026-08） | 自动检测任务 stage，只在进入同一 stage 的 rollout 间算组基线，stage 级优势只作用于对应区间 | RoboTwin 2.0 提升；LIBERO-Long 受控更新 | E3 |
| 失败反馈应止于何处 | [MART-GRPO](https://arxiv.org/abs/2610.32431)（2026-10） | 两个鞅刻画失败反馈终止点，非均匀分配 policy gradient | OpenVLA-OFT + RoboTwin 2.0 超 full-trajectory GRPO | E4（转述） |
| episode／step 两层分组 | [GiGPO](https://arxiv.org/abs/2505.10978)（NeurIPS 2025） | episode 级分组 + 同 state 下 step 级再分组，免 critic | ALFWorld +12%（LLM agent 语境） | E3 |
| 子目标 credit assignment | [HiRoC](https://arxiv.org/abs/2608.05999)（v1.0 §6.1） | 全局轨迹级 + 局部 subgoal 级 advantage 自适应加权 | LIBERO 93.5／Long 98.0；去全局 GRPO 掉到 4% | E3 |
| LLM 生成 dense reward | [TGRPO](https://arxiv.org/abs/2506.08440)（2025-06，与 Temporal GRPO 重名不同文） | 轨迹+步级优势 + LLM 任务分析自动构造 dense reward | LIBERO 平均 80.7（+4.2） | E3 |

**方法论警示**〔E4，转述〕：Brown 大学 2026 年工作报告 GRPO 在 LIBERO-Goal 上不优于 baseline，且初态成功率方差 0–80%——**LIBERO 上做 RL 必须钉死初始状态协议**。我们的固定 50 集（10 任务×5 官方初态）协议正好对齐此要求（见 [Motus README](../../../../Motus-joint-rl/README.md)，E2）。

## 6. 新增线 D：解耦式联合 RL（TEMPO）与大脑侧 RL（Robot-R1）

### 6.1 TEMPO：公开文献中最接近"双脑分别 RL"的配方〔E4，转述〕

[TEMPO: Semantic-Action Decoupled RL Post-Training for VLA Models](https://arxiv.org/abs/2608.07314)（2026-08）：冻结视觉组件，**语义与动作两路各自 RL 回路、双时间尺度**。这是"大小脑分别 RL 再协同"在公开文献里的最接近表述，与 v1.0 §8.3 的 B 组（有限解冻）设计直接对照。正文细节本轮未核，引用前须精读。

### 6.2 Robot-R1：只 RL 大脑的最简可复现组合〔E3，HTML 全文已核〕

[Robot-R1](https://arxiv.org/abs/2506.00070)（NeurIPS 2025）：Qwen2.5-VL-7B 上 GRPO（R1 式）训 embodied reasoning，输出 `<think>` + 下一 keypoint state 预测（MCQA 形式，格式+正确性 reward；RLOO 与 GRPO 相当）。**附录 F**：把 diffusion policy 头（借 GR00T-N1.5 代码库）接到 RL 后的 backbone 上，LIBERO 69.0→71.8，真机 16.67%→23.96%；低层仍 BC。"大脑 GRPO、小脑 BC"是当前最简单的分层组合。

### 6.3 Z-1 的工程增量（v1.0 §3.1 之外）

[已核 abs]：shared-prefix rollout（同组 rollout 共享视觉/语言前缀计算）、tree-structured trajectory branching、completion-aware reward calibration——这三个工程点正是联合 RL 解耦的抓手，与 π_RL 的 shared-prefix 思路同源。

### 6.4 DeepThinkVLA 的两条对齐原理（v1.0 §4.1 补充）

[已核]：**Decoding Alignment**——CoT 与动作需不同解码机制（语言因果、动作双向并行），混用单一自回归解码器掉 4.2pp；**Causal Alignment**——CoT 必须经结果导向 RL 与成功因果关联，否则监督 CoT ≈ 无推理基线。对双系统联合 RL 的损失设计直接适用（大脑推理链要靠 RL 与任务成功绑定）。

## 7. 新增线 E：世界模型×动作联合的新增样本

v1.0 §5 与扩线册 §3 已覆盖 WMPO／WoVR／WAM-RL／Motus2／VLA-RFT／WoVR+／DreamZero／FastWAM／LingBot；以下为本轮新增。

### 7.1 联合建模（SFT 系）

- **[UniWAM](https://arxiv.org/abs/2610.02054)**（2026-10，v4）[已核]：**physical reasoner（VLM）+ world generator（视觉生成）+ action predictor 三组件统一架构**——与 Motus 的"VLM＋Wan 视频分支＋Action/Understanding 专家"结构最同源的公开蓝本；低层动作以自然语言表示保护 VLM 语言能力；预训练把 VQA／第一人称人类数据／机器人演示的监督信号**分配给对应组件**；发现人机联训 log-linear 缩放律。无 RL。
- **[DUST](https://arxiv.org/abs/2510.27607)**（KAIST，ICML 2026）[已核]：action 流与 vision 流**各自保留独立扩散时间步／噪声扰动、解耦 flow matching loss**、跨模态共享知识；推理时异步采样 + inference-time scaling 再 +2–5%；RoboCasa/GR-1 超 SOTA 最高 +6%，真机 +10%。"共享 backbone 但损失解耦"的具体配方。
- **[WorldVLA](https://arxiv.org/abs/2506.21539)**（阿里达摩院，2025-06）[已核]：自回归世界-动作互促；发现 **action chunk 自回归生成时早期动作误差传播**，用注意力掩码在生成当前动作时屏蔽之前动作。"联合建模互相增益"的直接证据。
- **[LAP](https://arxiv.org/abs/2602.10556)**（Princeton，2026-02）[已核]：低层动作直接写成自然语言文本与 VLM 输入输出分布对齐，零 tokenizer；零样本跨本体 >50%（最强先前 2×）。与 UniWAM／Dream-1 的"动作即语言"互相印证。
- **[TriVLA](https://arxiv.org/abs/2507.01424)**（复旦，2025-07）[已核 abs]：三系统——VLM＋**video diffusion world model 作 episodic 记忆**（积累/回忆/预测）＋flow policy 条件于该表征，~36Hz。世界模型"当侧路"路线的代表。

### 7.2 想象 RL（世界模型当训练机器）

- **[Prophet／FlowScale](https://arxiv.org/abs/2511.20633)**（Logos Robotics，2025-11，v2 2026-08）[已核 abs]：**action-to-video 世界模型当 "rollout-ready simulator"**（大规模异构数据预训练、few-shot 适配），VLA 在想象 rollout 上 RL；算法 FlowScale＝Flow-GRPO + 内在 stepwise reweighting。公开基准 +5–17%、真机 +24–30%。与"WAM 小脑产生想象 rollout 供动作头 RL"的用法直接同构。
- **[WoVR 防幻觉三件套]**（[2602.13977](https://arxiv.org/abs/2602.13977)，v1.0 §5.3 已核）本册补充其工程要点：Keyframe-Initialized Rollouts（真实关键帧重启想象，降低有效误差深度）＋WM-策略协同进化＋可控动作条件视频 WM。
- **[WMPO 防漂移]**（v1.0 §5.3）：世界模型随策略行为数据微调保持同分布。
- **[WISE](https://arxiv.org/abs/2609.03681)**（2026-09）[已核]：只在交互关键状态调用想象（imagination scheduling）+ 有界 rollout，省约 80% GPU 时间；π0/π0.5 一致提升。
- **[World2Act](https://arxiv.org/abs/2603.10422)**（2026-03）[已核]：对比学习把 WM dynamics latent 与动作 embedding 对齐，后训练拉向**想象 latent 而非解码像素**（GR00T-N1.6 底座）；比像素空间 WM 监督最高好 +6.0%（LIBERO 上像素监督反而掉点）——"只借动力学先验不进像素 rollout"的轻量路径。
- **[Dreamer 4](https://arxiv.org/abs/2509.24527)**（DeepMind，2025-09）[已核]：世界模型内 imagination RL 的能力上限证明——**首个纯离线数据（零环境交互）Minecraft 钻石**；shortcut forcing 目标（少步生成保真）对视频分支推理加速有参考价值。
- **[Genie 3](https://deepmind.google/discover/blog/genie-3-a-new-frontier-for-world-models/) + [SIMA 2](https://deepmind.google/blog/sima-2-an-agent-that-plays-reasons-and-learns-with-you-in-virtual-3d-worlds)**（2025-08/11）[已核博客/转述]：世界模型=环境 + Gemini 当 reward 教师的自改进闭环；游戏域，机器人域未发表。
- **[VLA-World](https://vlaworld.github.io)**（上交＋**华为中央研究院**，CVPR Findings 2026）[已核项目页]：驾驶域但结构同构——predictive imagination（动作引导生成下一帧）+ reflective reasoning（对自己生成的未来帧推理修正），三阶段训练含 **GRPO（与生成的未来交互优化决策）**。"生成未来→反思→RL 优化决策"闭环的 GRPO 接法可参考。

### 7.3 推理期：大脑在想象里搜索、小脑执行

- **[τ₀-VLA](https://tau0-vla.github.io)**（2026-07）[已核项目页]：见 §1 抽查结果；"world model 推理期后果模拟 + value 打分"是 RL 之外利用世界模型的低成本方式。
- **[World Action Planner](https://arxiv.org/abs/2607.27599)**（MIT Yilun Du 组，2026-07）[已核]：粗到细两级想象搜索（全局 rollout 发现失败修正计划 + 局部 best-of-N 选邻近候选）；组合长程任务超 SOTA 端到端 policy 与 VLM planner。
- **[NWM](https://arxiv.org/abs/2412.03572)**（Meta/Berkeley，CVPR 2025）[已核]：1B CDiT 动作条件视频模型做 test-time 规划／轨迹排序／拒绝采样（导航域原型）。

## 10. 空白点重判（全网视角，对 v1.0 §1 的加强）

1. **学术侧**：四路检索未命中任何"独立 VLM Planner 与 WAM/VLA Executor 双端同时受任务奖励训练、带冻结/单端/双端完整消融"的工作（专项搜索 "joint RL both levels planner executor VLA" 零命中）；最近的三档：TEMPO（解耦双回路）、Z-1（selective joint）、π\*0.6（KI stop-gradient 的端到端）。〔E3 检索判断〕
2. **产业侧**：零公开配方（§0 结论 2）。Figure 的公开重心已转向预训练数据 scaling（Index 数据集＋scaling law），训练配方全黑箱。〔E3〕
3. **架构消解侧**：NVIDIA WAM 大一统路线（DreamZero→N2→Cosmos 3 Mixture-of-Transformers：自回归管离散 token＋DiT 管连续模态、**动作与未来相机画面联合去噪**）正在把"两侧"合并为单模型——该路线的后训练同样是 SFT 式，**单一 video-action 生成模型的 RL 后训练**是与双系统联合 RL 并列的空白。〔E3，NVIDIA [WAM glossary](https://www.nvidia.com/en-us/glossary/world-action-model/) 与 [Beyond VLAs 博客](https://developer.nvidia.com/blog/beyond-vlas-how-world-action-models-reshape-robot-manipulation/) 已核〕
4. **可做的研究表述**（承 v1.0 §8.2）：不是"能不能联合 RL"，而是"**什么类型的失败必须更新语义/世界表征，什么类型只需动作适配**"；想象 RL 线的第一问是"**World 是否收到任务奖励梯度**"（扩线册 §3.1）。VLM×VLA 联合 RL 的增量证据仍只有 Z-1（选定困难任务联合优于 AE-only）对 π_RL（LIBERO 上联合收益不明显）一正一负两例。

## 12. 术语与写作注意

- **WAM 公开定义**：NVIDIA [glossary](https://www.nvidia.com/en-us/glossary/world-action-model/)——"learns both how the world is likely to change and what actions a robot can take to shape that change"；Galbot AstraBrain-WAM 同义。**公开语境的 WAM 是替换 VLA 的大一统模型（4–64B），不是小脑尺寸的轻量专家**——我们内部"VLM＋WAM"里的 WAM（Motus 整体 8B）对外写作时须注明区别，避免与 GR00T N2 语境混淆。〔E3〕
- **VLA post-training** 2026 年通行含义＝SFT 与 RL/RFT 两种 primitives 统称（RLinf-Co 论文原文措辞），不等于 SFT-only。〔E4，转述〕
- 引用警示汇总：§2 纠错表 15 项；LaST-R1 99.9%（抽查 #4）；任何 VLM-as-reward 配线先过 RoboRMBench。
