# 2026-10-26 ~ 11-01 具身蒸馏调研

目录名沿用开周时的主题。本周实际是「调研为主、三条实验线并行」：具身蒸馏与联合后训练 RL 调研是主线，另有 Motus、DreamLab、HomeBody 三条线各有报告。11-10 成文的专题链接清单是与本周调研相互独立的新调研，已于 2026-11-23 整理时移至 [11/9–11/15 周](../2026_1109-1115_Qwen换脑与HALO调研/readme.md)。

**具身RL统一阅读入口**：[具身RL重点研究综合报告](2026-10-30-具身RL重点研究综合报告.md)——2026-11-03将研究分析、训练详表、静态图册按研究问题与训练路线整合；原三份保留追溯。

## 本周目标

- **调研**：从精读 [arXiv 2609.24682](https://arxiv.org/abs/2609.24682)（世界模型表征蒸馏进紧凑 VLA）出发，完成具身智能知识蒸馏六条线的并行调研，产出方法地图与经验清单 → [具身蒸馏调研报告.md](具身蒸馏调研报告.md)
- **调研**：梳理大小脑联合后训练与 RL 的研究路线，给出可对照 Motus／DreamLab 的优先阅读清单、训练详表与图解。
- **Motus**：给出昇腾 910B3 上 LIBERO-Long 多任务 SFT 的阶段报告，并把训练续到设定上限。
- **DreamLab**：在官方 RoboDojo-Sim 四瓶入桶任务上完成 Dream-1 与 GPT-6 Astra 的全批次对比分析。
- **HomeBody**：完成 HomeBody 仿真部分的复现并成文。
