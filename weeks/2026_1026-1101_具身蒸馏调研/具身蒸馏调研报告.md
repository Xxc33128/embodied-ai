# 具身智能中的知识蒸馏：方法地图与经验总结

- **日期**：2026-10-26
- **触发**：精读 [arXiv 2609.24682](https://arxiv.org/abs/2609.24682)（Think Like a World Model, Act Like a VLA：把 Cosmos3-Nano 世界模型表征余弦对齐进 0.8B QwenGR00T，LIBERO 97.9%、部署图零改动）后，对其辐射出的六条蒸馏支线展开并行调研。
- **方式**：6 个并行调研 agent 分线抓取论文原文／官方页面后综合。**所有数字转引自论文原文，未做独立复核，按工作区分级属 E3（文档实证）**；个别抓取受限处已标注（见 §2.2 MiniVLA、§2.5 MiniUAV-VLA）。
- **覆盖**：1 篇锚点精读 + 17 篇分线论文 + 2 篇综述 + 若干延伸线索。

## 0. 一页结论

1. **蒸馏什么：latent/特征全面优于 pixel/logits。** 特征线全用 L2/MSE/余弦/KL 对齐隐层；SimDist 实证加 pixel reconstruction 损失反而严重掉点（0.32/0.21）。综述口径一致：世界模型的收益"来自 predictive representation 的程度不亚于显式 test-time imagination"。
2. **表征内容上，动作导向 > 语义规划。** ERVLA 消融：Movement +4.1、Point trajectory +4.8，而 Goal/Planning/Reasoning 单独用反而小降。
3. **"教师只留训练期"是工程共识。** 教师特征离线缓存、投影器训后丢弃、语义标注离线生成（$7/81k 帧），部署图与基线逐算子一致；反面教材是 CoT-VLA 的自回归 subgoal 生成带来 ~7× 持续推理开销。
4. **on-policy + dense per-token 监督是效率上限。** 把 KL-regularized RL 里的 reference model 换成教师、reward 换成 −reverse-KL，即得 on-policy 蒸馏（"一行改动"）；dense 信号降梯度噪声 → 更小 batch、更少步数（LLM 上 7–10× 步数、50–100× compute；VLA 上 ~3× vs GRPO）。
5. **速度收益的真实来源排序：动作解码方式 >> 骨干规模。** TinyVLA：7B→1B 只把 292ms 降到 140ms，剩下 10× 来自非自回归动作头（14ms）；RT-VLA 靠"控制走小分支、语言走离线分支"的解耦拿到 44.8×。
6. **少步化必须带分布锚。** 1 步 DDIM 直接崩到 0%；而 consistency 项 + DSM 锚（Consistency Policy）、score-difference KL（OneDP）、EMA 自教师 + FM boundary loss（OFP）都能做到 1 步持平甚至反超多步教师。
7. **蒸馏与 RL 可叠加。** 两段式（VLA-OPD：蒸馏 87.4% → 蒸馏+GRPO 93.4%）或联合正则（D-PPO：α·蒸馏 MSE + β·PPO，蒸馏项当稳定锚、RL 项提供超越空间）。
8. **增益规律分层：in-domain 饱和处趋零；泛化/sim2real/双臂长程场景 +3~8 点至一个量级。** 选基准时要认清自己站在哪一档。
9. **特权教师的设计原则是"最小特权 + 感知可重建"**：教师只拿学生理论上能从传感器历史推断的东西（D-PPO：过多特权反而注入错误监督）。
10. **勘误警示：文献里 "policy distillation" 双向都存在**（RLDG 实为 RL 专才生成数据喂通才学生的 BC），引用前必须核对教师-学生方向。

## 1. 方法地图：六条线

| 线 | 教师 → 学生 | 蒸馏对象 | 代表论文 | 部署代价 |
|---|---|---|---|---|
| ① 世界模型/感知专家 → 策略 | 冻结世界模型/3D 跟踪器 → VLA | 池化特征（L2/余弦） | 2609.24682、Track4Action、TWIST、SimDist、WMSD | 零（缓存+丢弃投影器） |
| ② VLA 压缩 | 大 VLA/RL 专家 → 小策略 | 动作级/logits/特征多层次；或仅权重初始化迁移 | TinyVLA、MiniVLA、RT-VLA、VLA-AD | 零（学生本来就在） |
| ③ 扩散/流策略加速 | 多步去噪教师（或 EMA 自教师）→ 1–2 步学生 | 速度场/score/自洽映射 | Consistency Policy、OneDP、OFP | 负（推理变快 9–183×） |
| ④ RL × 蒸馏 | RL 专才 ↔ 通用 backbone（两个方向都有） | per-token reverse-KL 当 reward；或 RL 轨迹当语料 | VLA-OPD、RLDG、TM 博客 | 零 |
| ⑤ 特权 sim2real（经典线） | 仿真特权教师 → 本体感知学生 | 动作（DAgger MSE） | HOVER、D-PPO、Lee'20/Miki'22 | 零 |
| ⑥ CoT/推理 → 策略 | foundation model 自动标注 → 推理监督 | 文本推理链（显式 token 或训练信号） | ECoT、ERVLA | 显式 CoT 高延迟；dropout 化后零 |

锚点篇（2609.24682）的完整精读笔记在对话中已过，这里只留一句：**0.8B 学生 + 冻结 Cosmos3-Nano 特征余弦对齐 + 离线缓存，LIBERO +2.6 至 97.9%，部署图逐算子不变**——它是①线的最新代表，也是本报告展开的引子。

## 2. 分线笔记

### 2.1 线①：世界模型/感知专家 → 策略

共性：教师吃"特权输入"（演示片段的 3D 跟踪、privileged state、详细文本条件），学生只看部署可得输入；损失全部落在 latent 空间。

**Track4Action（[2608.03727](https://arxiv.org/abs/2608.03727)）**
把演示片段的 world-centric 3D 跟踪特征（Track4World，冻结）蒸馏进 VLA：learnable track queries 经 cross-attention 读 VLA hidden states，与教师池化特征做共享空间 L2 对齐，同一组 queries 经 feature-wise gate 注入 flow-matching DiT 动作头；联合训练、推理零开销。LIBERO-Plus zero-shot 82.3%（OpenVLA-OFT 69.6、π0-FAST 61.6）；RoboTwin 2.0 双臂 80.4/81.5% vs π0.5 的 43%。去掉对齐掉 7.6~40 点。局限：需时序连续 clip、独立运动物体削弱关联、可变形操作弱（毛巾折叠 40% vs π0.5 的 70%）。
→ 与 2609.24682 是同年同问题的对照组：教师选"3D 跟踪专家"而非"世界模型"，增益更大（尤其双臂/长程），说明**表征教师的选择空间还没收敛**。

**Simulation Distillation / SimDist（[2603.15759](https://arxiv.org/html/2603.15759v1)，UW/UT Austin/FieldAI）**
方向反过来：把仿真器的 privileged 结构（dynamics/reward/**value**）蒸进 TD-MPC 式 latent world model，真机只短时 finetune dynamics。数据故意混 suboptimal checkpoints 与扰动（expert 仅 ~36%）。UR5e 装配约 2× 最强基线；Go2 32–36 min 真机数据后 5/5 成功（zero-shot 0/5）。两个重要消融：10% 数据量或 expert-only 数据都大幅掉点；**pixel reconstruction 损失有害**。adaptation 期全冻结只调 dynamics 的"最小自由度适配"值得抄。

**World Model Self-Distillation / WMSD（[2606.12072](https://arxiv.org/html/2606.12072v1)，Bern）**
同一 video diffusion 底座做"条件自蒸馏"：Demonstrator 条件是 VLM 生成的详细执行描述，Executor 条件是短任务 prompt；teacher-student velocity discrepancy 既当 distillation reward 又当 anchor loss，与 AWM/FlowGRPO 交替训练。WorldTasks-Bench 0.455→0.726 反超教师。防 reward hacking（物体凭空出现/消失）靠 consistency reward；on-policy 优于 off-policy。→"教师只在文本条件侧更强，学生去掉该条件"是条件蒸馏的通用范式。

**CoT-VLA（[2503.22020](https://arxiv.org/abs/2503.22020)，NVIDIA/Stanford，CVPR 2025）**
非蒸馏，近亲：VLA 内部自回归生成 subgoal 图像再出动作 chunk。LIBERO 81.1%（OpenVLA 76.5），真机超当时 SOTA 17%。但 OOD 任务上用 GT goal image 替换生成的 subgoal 可 +40 绝对点（20→60%）——subgoal 生成质量是瓶颈；且 ~7× 推理减速。→ "推理显式化"的代价反面教材。

**TWIST（[2311.03622](https://arxiv.org/abs/2311.03622)，Oxford，ICRA 2024）**
state-based Dreamer 教师 + 同构 image-based RSSM 学生，轨迹级 MSE+双 KL 对齐，还加**想象对齐**（教师带噪 rollout H=15 步、学生回放同一动作序列对齐）——多步一致性对齐是关键成分。**policy 不蒸馏**：学生 latent 对齐教师后直接复用教师 actor。真机 Franka 比纯 DR 高约一个量级。

### 2.2 线②：VLA 压缩

**TinyVLA（[2409.12514](https://arxiv.org/abs/2409.12514)）**
小 VLM 初始化迁移 + Diffusion Policy 动作头（422M/740M/1.3B 家族），不走 logits 蒸馏。真机 94.0% vs OpenVLA 68.3%；延迟 292ms→14ms（~20×）。核心消融：**action head 形式决定成败**（DP ~94% vs ACT ~13% vs MLP 0%）；换小骨干只贡献 2×，其余来自非自回归动作头。

**MiniVLA（[SAIL 博客](https://ai.stanford.edu/blog/minivla)，[代码](https://github.com/Stanford-ILIAD/openvla-mini)）**
OpenVLA 7B→1B 的"官方小号"：Qwen2.5-0.5B + DINOv2/SigLIP 双视觉编码器，VQ action chunking（VQ-BeT 式残差 VQ），词表外扩 256 个专用 action token。单张 L40S 12.5 Hz（OpenVLA 5 Hz）。博客 TLS 抓取受限，SimplerEnv 逐任务数字以搜索快照为据〔E3，谨慎引用〕。→ 已成后续小 VLA 的标准底座；"离散 action token 设计"是 FAST 一脉的源头之一。

**RT-VLA（[2606.14010](https://arxiv.org/html/2606.14010v1)，自动驾驶域）**
SimLingo 式驾驶 VLA 蒸馏进轻量学生：visual features/query/waypoint（MSE/L1）+ language logits（温度 KL）多层次监督，语言分支独立且离线事后生成（Perceiver Resampler 压 token + KV cache），另有 DAgger 式 on-policy 语言微调修 train/inference 偏移。Bench2Drive DS 85.19 持平教师，每帧 34.48ms（~29 Hz）vs 教师 1544ms（44.8×）。去蒸馏 DS 从 85.17 崩到 34.05。→ **"控制走小快分支、语言走离线分支"的解耦架构**是通用提速模式。

**VLA-AD / Offline Semantic Guidance（[2605.16241](https://arxiv.org/abs/2605.16241)）**
OpenVLA-7B/π0.5-4B 蒸成 158M 学生（可训仅 8.6M）：动作级模仿（7 维×256 bins 带权离散 CE，旋转维权重 ×2）+ **离线 VLM 语义标注**（9 类 task phase + 操作方向元组，81k 帧成本约 $7）。LIBERO 学生与 OpenVLA 教师平均差 −0.27%；π0.5 学生 94.5 甚至超教师 90.5；gripper 虚假翻转 27→1。→ 语义监督是近乎零成本的蒸馏增强；作者自列局限（单 seed、仅 in-domain、teacher-agnostic 只验证 n=2）值得引用时注明。

**MiniUAV-VLA（[MDPI Drones](https://www.mdpi.com/2504-446x/10/8/572)）**
QMIX 多智能体专家 → 158M VLA 的 BC 蒸馏。唯一值得记的工程点：**prompt-end action pooling**（在 user-prompt 末端而非生成回复后抽 hidden state）单项 +35.6 点——生成式 backbone 输出动作时，特征抽取位置是隐性大坑。〔MDPI 403，经 BUAA 门户镜像确认，E3〕

### 2.3 线③：扩散/流策略加速（对 GR00T 式动作专家最直接）

**Consistency Policy（[2405.07503](https://arxiv.org/abs/2405.07503)，Stanford）**
ℒ_CP = α·ℒ_CTM + β·ℒ_DSM：CTM 式自洽（同一 PF-ODE 上 t→s 带梯度 vs u→s stopgrad，均映回 time 0，pseudo-Huber）+ DSM 分布锚。8GB 消费卡上 198ms→21ms（端到端 ~9×）。关键消融：免教师的 from-scratch consistency training 仅 .55（失败）；对教师质量鲁棒（.84 教师蒸出 .88）。技巧：初始噪声方差降为 1/T²、3 步 chaining 用离散网格预设、生成时 dropout 0.2。

**OneDP（[2410.21257](https://arxiv.org/abs/2410.21257)，NVIDIA，ICML 2025）**
KL/score distillation：学生生成的动作加噪到随机 timestep k，最小化 reverse KL（梯度 = 加权 score-difference），蒸馏成本仅预训练的 2–10%。确定性 Dirac 学生变体免辅助网络、真机仅掉 3 分——工程优先选它。真机 0.98 vs DDIM-10 的 0.83，控制频率 1.5→62 Hz。

**One-Step Flow Policy / OFP（[2603.12480](https://arxiv.org/abs/2603.12480)）**
**对 flow matching 最直接的模板**：免预训练教师，EMA 自教师 + 三件套——①self-consistency 学区间平均速度场（time-contracting schedule 做课程，避开 MeanFlow 的 JVP）；②self-guided regularization（EMA 教师估 CFG-Augmentation 项锐化到高密度模态）；③boundary anchoring（对角 t=r 保留标准 FM loss）。π0.5 动作专家压到 NFE=1 后 RoboTwin 2.0 均值 94.7% **反超 10 步原版**；另有免训练的推理 warm-start（上一 chunk 未执行后缀平移当先验）。仅仿真验证。

### 2.4 线④：RL × 蒸馏

**VLA-OPD（[2603.26666](https://arxiv.org/abs/2603.26666)）**
三阶段循环：学生 on-policy 采 G 条轨迹 → 冻结 RL 教师对学生**访问过的每个状态**打 token 级 logits → policy-gradient 更新，intrinsic reward = −reverse-KL（无 GAE、无 critic、无 group normalization）。LIBERO 48.9→87.4→93.4（教师 93.9）。熵行为三态：forward-KL 熵爆炸、hard-CE 熵坍缩、reverse-KL 有界健康。G=2 仍 >80%，rollout 预算紧时优先保 batch。

**RLDG（[2412.09858](https://arxiv.org/abs/2412.09858)，RSS 2025，**UC Berkeley：Charles Xu, Qiyang Li, Jianlan Luo, Sergey Levine**——非 PI/Black 系，方向为 RL 专才→通才学生）**
HIL-SERL 专才（1–3 小时练到 100%）自主 rollout 过滤失败后当 BC 语料喂 OpenVLA/Octo。比等量人类演示高至多 40%；45 条 RL episode 抵 300 条人类演示。关键消融：**用 RL 动作重标注人类轨迹即恢复 >50% 增益**——优化过的动作分布比状态覆盖更关键（人类动作聚在 action space 中心，RL 动作指向正确方向）。

**On-Policy Distillation（[Thinking Machines 博客](https://thinkingmachines.ai/blog/on-policy-distillation)，2025-10）**
方法论文（LLM 域）：SFT=off-policy+dense、RL=on-policy+sparse，on-policy distillation=on-policy+dense 兼得两者。实现即"KL-regularized RL 里把 reference model 换成教师"；discount=0。7–10× 更少 gradient steps、50–100× 更少 compute；LoRA rank 32 蒸馏后仅落后全参 6%（SFT 后落后 13%）。警示：即便在学生自采样数据上做 SFT 也掉 IF-eval——**损害来自 off-policy 本身，不是数据来源**。

### 2.5 线⑤：特权 teacher–student（经典 sim2real 线）

**HOVER（[2410.21229](https://arxiv.org/abs/2410.21229)，NVIDIA，ICRA 2025）**
人形全身控制的多模式统一：特权 oracle（全刚体状态，goal-conditioned PPO 模仿 retarget 过的 AMASS）→ 纯本体感知学生（25 步 action history），标准 DAgger MSE。**多模式不是靠多教师混合，而是命令空间的 mode mask（one-hot）+ Bernoulli(0.5) 采样的 sparsity mask**——训练与蒸馏阶段都施加，即得免重训练的在线模式切换（15+ 模式，32/32 metric-mode 组合优于从零多模式 RL）。sim-to-data retarget 过滤不可行动作降低蒸馏目标噪声。

**Distillation-PPO / D-PPO（[2503.08299](https://arxiv.org/html/2503.08299v1)）**
α·蒸馏 MSE + β·PPO 联合（α=β=0.5），学生继承教师权重近似 self-distillation。论点：纯 DAgger 学生被教师封顶且仿真误差注入错误监督；联合优化让学生可超越教师。无量化指标是硬伤，但"蒸馏当正则、RL 当超越空间"的定性结论与 VLA-OPD 两段式互相印证。

**背景线勘误与定位**〔E3〕：Lee et al. 2020（Science Robotics，ANYmal）= 特权教师→本体感知学生的起点；*perceptive locomotion in the wild* 那篇实为 **Miki et al. 2022**（attention 融合外感/本体）；**Rudin 2021 "Walk in Minutes" 本身无蒸馏**（单阶段 RL 直接吃特权式地形采样，仅 future work 提及合并 teacher-student）——legged_gym 生态里的 teacher-student 是 Lee/Miki 一脉的再实现。Isaac Lab 官方已把"特权教师→本体感知学生 + DAgger"写成[标准教程](https://docs.nvidia.com/learning/physical-ai/getting-started-with-isaac-lab/latest/robot-learning-fundamentals/07-policy-distillation.html)，并强调师生动作空间/控制频率必须逐位一致、蒸馏损失低≠任务成功。

### 2.6 线⑥：CoT/推理 → 策略

**ECoT（[2407.08693](https://arxiv.org/abs/2407.08693)，CoRL 2024）**
OpenVLA + 自回归推理链（"think carefully"任务/规划 + "look carefully"几何 grounding），foundation model 检测器/几何投影**自动合成标注**。真机 +28% 且不加机器人数据。fast 版用蒸馏+并行解码保 3× 加速。价值一半在泛化、一半在可解释与人在环纠正。

**ERVLA / Revisiting ECoT（[2606.03784](https://arxiv.org/html/2606.03784v1)）**
把 CoT 从"可见推理轨迹"降格为"训练信号"：978k 轨迹/226M 样本的自动标注语料（Qwen3.5-397B 逐 episode 标 action 导向字段）+ **reasoning dropout**（随机 /cot 与 /no_cot 切换，消 CoT contamination：Gripper −5.6→−0.8）。LIBERO-Plus 86.9% SOTA 超 π0.5；choice policy（候选动作块打分）去掉后 86.9→61.9。**自回归 CoT 不随数据 scale（加数据反掉 3.6），ERVLA 随数据稳步升**——显式推理造数据、隐式表征来承载，是当前形态。

### 2.7 两篇综述的导航

- **World Model for Robot Learning（[2605.00080](https://arxiv.org/html/2605.00080v1)）**：Sec 3 按策略耦合方式分五范式（IDM 式解耦 / 单骨干 / MoE-MoT 双专家（**含 Motus**）/ Unified VLA / JEPA latent）；蒸馏相关散布在 3.2（VPP/Video2Act）、3.4（FRAPPE 专家间 latent 对齐）、**3.6（最完整：JEPA-VLA、FLARE Future Latent Alignment）**、5.2（DreamGen）。
- **World Models for Robotic Manipulation（[2606.00113](https://arxiv.org/html/2606.00113v1)）**：三轴（预测什么表征：image→latent→scene flow→3D/4D→physics；怎么接控制；何时用）。关键论点在 Sec IV-A：预测目标的收益"来自 predictive representation learning 的程度不亚于显式 test-time imagination"。

## 4. 经验清单

### 4.1 可复用配方

1. **REPA 式特征对齐（线①）**：冻结教师特征 → 学生池化特征 → 两层 MLP 投影 → 余弦/L2（stop-gradient）→ λ=0.5 量级；教师特征 memory-mapped 离线缓存，投影器训后丢弃。增益 +2~8 泛化分，零部署代价。
2. **一步流策略三件套（线③，OFP）**：EMA 自教师 + time-contracting 自洽课程 + 保留 FM loss 作 boundary anchor；推理 warm-start 复用上一动作块后缀，免训练。适配 GR00T/π0.5 式 flow matching 动作专家的路径：给速度头加 interval 条件（RMSNorm 注入）。
3. **on-policy 蒸馏套现成 RL 框架（线④）**：GRPO/PPO 代码里 reference model → 教师，reward → −reverse-KL（discount=0，无 GAE）；可作环境奖励 RL 精调前的 warmup 段。
4. **离线语义/推理标注增强（线②⑥）**：VLM 对训练帧打 phase/方向/推理字段，仅训练期注入；成本两个数量级低于微调教师。
5. **控制/语言解耦（线②）**：控制走轻量分支实时出动作，语言/解说走离线分支事后生成——多模态 VLA 提速的架构级模式。
6. **特权最小化（线⑤）**：教师只拿学生"感知可重建"的量；retarget/过滤不可行动作降低蒸馏目标噪声。
7. **RL 数据当蒸馏语料（线④）**：RL 专才过滤失败后的 rollout 是优质 SFT 数据（45 条抵 300 条人类演示）；长程任务混合喂非瓶颈阶段。

### 4.2 反模式 / 坑

- **pixel reconstruction 监督有害**（SimDist：0.32/0.21）；latent 目标全面优先。
- **无锚定的少步化灾难**：1 步 DDIM 归零、DDiM-9 的 ToolHang .79→.14；from-scratch consistency 仅 .55。自洽类目标必须配分布锚（DSM/FM/教师 KL）。
- **熵行为三态**：forward-KL 熵爆炸、hard-CE 熵坍缩、reverse-KL 有界健康（VLA-OPD）。
- **off-policy 本身就有害**：学生自采样数据上做 SFT 照样掉能力（TM 博客）；蒸馏方向（在谁访问的状态上监督）比数据来源更本质。
- **CoT contamination**：显式推理字段污染动作 token（ERVLA：−5.6/−6.1），需 reasoning dropout 缓解；自回归 CoT 不随数据 scale。
- **特征抽取位置**：生成式 backbone 出动作时在生成回复后抽特征是错的（MiniUAV-VLA 的 prompt-end pooling +35.6 点）。
- **multimodality 丢失**：确定性单步蒸馏偏向单一模式（Consistency Policy 明确报告）；对冲办法是保留 FM loss + interval 条件化。
- **文献陷阱**："policy distillation" 双向都存在（RLDG 是专才→通才），先核对方向再引用。

### 4.3 增益与代价的规律

- 分层规律：in-domain 饱和基准 +0~3；泛化类（LIBERO-Plus/OOD）+3~8；sim2real/双臂/长程可达 2×~一个量级。**报道增益先看基准难度档位**。
- 速度收益来源排序：动作解码方式（自回归→diffusion/flow/VQ chunk）>> 骨干规模 >> token 压缩。
- 各文延迟数字硬件不一（A6000/L40S/A100/4090/V100/3070Ti），横向比较必须换算。
- 常见评测短板：单 seed、仿真为主、OOD/真机薄——引用数字时留意。

## 5. 与当前工作的结合点

1. **Motus 联合训练**：综述 [2605.00080] Sec 3.4 把 Motus 列为 MoE/MoT 双专家范式的代表——写 Motus 相关报告时可引该节做架构定位。若联合训练遇到生成回路代价/稳定性问题，线①的"表征对齐 + 离线缓存"是现成降级方案（教师世界模型不必常驻 NPU）；若后续接 RL 阶段，线④的两段式（on-policy 蒸馏 warmup → GRPO）和 RLDG 的"RL 轨迹当语料"都可直接平移。
2. **DreamLab 评测**：[2606.00113] Sec IV-A 的论点（收益来自 predictive representation 不亚于 test-time imagination）支持"评世界模型时审计表征质量，而非只看生成质量"的审计角度——与我们已做的观测/控制审计天然衔接；其 Sec VI lifecycle（pretraining/post-training/inference）可当评测维度清单。
3. **GR00T 系 NPU 部署**：OFP 是流匹配动作专家降到 NFE=1 的最直接模板（含 π0.5 集成细节）；RT-VLA 的控制/语言解耦和 TinyVLA 的"延迟大头在动作头"结论对昇腾侧吞吐规划有直接参考价值。
4. **LIBERO-Long**：增益规律显示长程/接触富任务是表征先验最弱、动作导向监督最强的场景（Track4Action 长程增益最大、ERVLA 的 Movement/Point 字段最有效）——与我们复现中 LIBERO-Long 偏弱的观察互证；若做增强实验，优先考虑动作条件化的表征监督而非语义监督。
