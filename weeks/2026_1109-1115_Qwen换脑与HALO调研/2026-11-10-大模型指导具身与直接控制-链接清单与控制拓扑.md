# 大模型指导具身模型 / 直接控制机器人：原文链接清单与控制拓扑核对

> 2026-11-10 整理。条目与链接取自 [10/26–11/1 周的三份调研报告](../2026_1026-1101_具身蒸馏调研/readme.md)、0928/1019 周评测现场与 11 月上旬日报，出处均沿用来源报告的核验标注（多数 E3；Helix 2.5 为 E4）。
>
> 归周说明：本篇成文于 11-10，是与蒸馏调研相互独立的新专题，按「独立的新调研进入新周」规则于 2026-11-23 整理时自 10/26–11/1 周移入本周。
>
> **控制拓扑核对结论**：并非全部条目都是"VLM 在最高层控制"。按大模型在控制回路中的位置分五类：
>
> - **A 层级双脑**：VLM/LLM 在最高层，下接低层策略——严格满足"VLM 在最高层"；
> - **B 直接控制**：大模型自己就是控制器（直接出动作/工具调用），没有更低层的具身策略——满足"直接控制机器人"，但没有"被指导的低层"；
> - **C 推理内嵌**：高层推理与动作输出在同一 VLA 骨干内，不是两模型层级；
> - **D 仅离线参与**：大模型只在训练期造数据，不在控制回路；
> - **E 非层级条目**：评测协议、综述、训练期机制，与该判据无关，列此仅作导航。

## A. VLM/LLM 在最高层，下接低层策略（层级双脑）

- GPT-as-Policy（无公开论文页；本地 upstream clone：`GPT-as-Policy-repro/upstream/GPT-as-Policy/`）——GPT 高层出动作/子目标、π 底层执行；我们的 LIBERO-PRO 复现主线。
- [RPent (arXiv 2607.08448)](https://arxiv.org/abs/2607.08448)——双脑对照复现对象；我们 120 集实测中大模型作慢脑在环境里直接闭环（原文架构细节以论文为准）。
- [SaiVLA-0 (arXiv 2603.08124)](https://arxiv.org/abs/2603.08124)——Cerebrum（冻结大模型）→ Pons Adapter → Cerebellum：大脑只供多模态先验，小脑可单独 RL。
- [InternVLA·M1 (GitHub)](https://github.com/InternRobotics/InternVLA-M1)——上海 AI Lab"思考–行动–自主学习"双系统闭环：思考（VLM）在上、行动在下（开源仓库，未见 arXiv）。
- [RoboDual (arXiv 2410.08001)](https://arxiv.org/abs/2410.08001)——VLM 规划 + Diffuser 执行专家的协同双系统（SFT 系，无 RL）。
- [GR00T N1.7 (HF Blog)](https://huggingface.co/blog/nvidia/gr00t-n1-7)——NVIDIA "Open Reasoning VLA"：System 2 VLM 推理在上、System 1 快策略在下（官方博客，非论文）。
- Helix 2.5（无公开链接）——Figure S1/S2 双系统栈最新版〔E4，日报转引，链接待官方页替换〕。
- [τ₀-VLA (arXiv 2608.16885)](https://arxiv.org/abs/2608.16885)（[项目页](https://tau0-vla.github.io)）——分层机器人基础模型，高层用世界模型做测试时推演，"先想再做"。

## B. 大模型自己直接控制（无低层具身策略）

- [GPT-6 Astra on robot arms (RoboCurve)](https://openai.robocurve.org/gpt-6-astra/)——LLM agent 经 inspect-robots 的 `move_*` 工具调用直接控 I2RT YAM 双臂 pick-place（19/20=95%；我们复现的是协议，数字不可直接比）。
- [PyRUA-REAL (arXiv 2611.06768)](https://arxiv.org/abs/2611.06768)——LLM agent 遥操作的真机姊妹篇：真机探索与自适应学习（前作 PyRUA-DataFarm「LLM agent 遥操作」）。
- [LAP (arXiv 2602.10556)](https://arxiv.org/abs/2602.10556)——Princeton：低层动作直接写成自然语言文本与 VLM 输入输出分布对齐，VLM 以文本直接输出动作，零 tokenizer，零样本跨本体 >50%。
- [Dream-1 (Dream Labs)](https://dreamlabs.ai/research/dream-1)——产品化 WAM 直接输出关节角或 EEF pose+gripper：属于世界模型直接控制，而非"VLM 指导低层策略"；RoboDojo-RC Tier 1 得 59 分。
- [Psi-R1 / Psi-R2+W0（灵初官方页）](https://www.psibot.net/008_zh/)——WAM 联合预测未来帧×动作，再用 RL 把人手轨迹转成机器人动作；Psi-R1 宣称"大脑通用泛化"，部署期拓扑未核〔E3〕。

## C. 高层推理内嵌在单一 VLA 骨干（非两模型层级）

- [ECoT (arXiv 2407.08693)](https://arxiv.org/abs/2407.08693)——推理链嵌在 OpenVLA 同一骨干内（推理 token 在动作 token 之前），检测器自动合成推理标注，真机 +28%。
- [How Much Should a VLA Trust Its Reasoning? (arXiv 2610.40002)](https://arxiv.org/abs/2610.40002)——把推理输出量化为步级 action-value 函数，在同模型内指导动作选择，决定"该信多少"。

## D. 大模型仅离线参与训练，不在控制回路

- [ERVLA (arXiv 2606.03784)](https://arxiv.org/abs/2606.03784)——Qwen3.5-397B 只离线逐 episode 自动标注训练语料（978k 轨迹）；部署侧无大模型在环，CoT 是训练信号不是运行时层级。LIBERO-Plus 86.9%。

## E. 非层级条目（协议 / 综述 / 训练期机制）

- [World-VLA-Loop (arXiv 2602.06508)](https://arxiv.org/abs/2602.06508)——video 世界模型与 VLA **训练期**闭环共同进化，非部署期控制层级。
- [Compounding Physical RSI (arXiv 2611.06654)](https://arxiv.org/abs/2611.06654)——"失败→数据→能力"复利式自改进闭环；控制拓扑为日报级转引，未核〔E3/E4〕。
- [RoboDojo (arXiv 2607.04434)](https://arxiv.org/abs/2607.04434)——Robocurve 的评测协议/榜单，不是控制架构（协议名，非公司名）。
- [World Model for Robot Learning 综述 (arXiv 2605.00080)](https://arxiv.org/html/2605.00080v1)——按策略耦合方式分五范式（含 Motus 的 MoE-MoT 双专家）。
- [World Models for Robotic Manipulation 综述 (arXiv 2606.00113)](https://arxiv.org/html/2606.00113v1)——三轴组织（预测什么表征/怎么接控制/何时用）。
