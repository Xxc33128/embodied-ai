## 3. 分支架构（源页 01 节）

| | 冻结主线 `main @ 6f7bbb8` | 实验分支 `codex/sonic-interface` |
|---|---|---|
| 语义 | VLM 按任务和场景选技能；默认 Astra（`gpt-6-astra`），可配置替换 | 本地解析或 VLM 把一句话变成结构化意图；实跑用过 Astra 和 DeepSeek V4.1 Flash |
| 动作来源 | 导航、抓取、放置技能按几何和反馈算步态、手臂、握持目标 | ARDY-G1 生成 25 Hz 身体参考；明确的姿态任务走本地 FK／IK |
| 控制 | AMO + Adapter 管平衡和步态，手臂与 Dex3 管操作 | 冻结的 SONIC ONNX 策略跟踪参考 |
| 物理与反馈 | MuJoCo；观测与技能结果回给 VLM | MuJoCo 力矩仿真；实测身体状态回给 SONIC 和本地编排 |

两条链路都在 MuJoCo 中执行，差别在语义输出、参考生产方式和身体控制器。〔E3，源页与 `guides/sonic-architecture.md` 的架构说明〕

实验分支逐层的输入与输出：

| 层 | 输入 | 输出及用途 |
|---|---|---|
| ① 指令入口 | 一句开始、修改或停止指令；会话的当前执行状态 | 带请求标识的原话及对应上下文，交给本地解析或 VLM |
| ② 语义 | 用户原话；走 VLM 时附带可用机器人图像、近期执行状态、当前修订和目标 | 新建 `MotionIntent`（动作描述、阶段、路由、目标、完成条件），更新 `IntentPatch`（基准修订、增删保留的目标、绝对值或增量），或停止。已支持的明确掌位可由本地解析直接产生同一协议 |
| ③ 本地编排 | 类型化意图、实测状态、已调度参考 | 选 `generate` 或 `pose`，提交 `GenerationRequest`（任务与修订、目标、历史及哈希、计划起帧，在线拼接还带接缝上下文和截止时间）；按达标、计时或结束条件切换阶段、补窗和停止 |
| ④A `generate` | ARDY 文本编码器（冻结的 Meta-Llama-3-8B-Instruct）产出的文本特征；续窗还用已调度历史；适用的掌位目标参与引导或适配 | ARDY-G1 采样新的 25 Hz 身体运动。适配层重定向并重采样为 50 Hz 候选（29 关节位置及速度、根位姿） |
| ④B `pose` | 掌位或掌向目标、起始姿态、G1 几何及关节限制 | 本地标定与逆运动学求姿态，生成同样格式的 50 Hz 候选。运行中的生成任务若只改掌位，可以继续走 ④A |
| ⑤ 准入 | 带任务、修订、起帧和历史哈希的候选；同一时刻已调度的参考 | 检查版本、历史、接缝与适用的运动和目标约束，通过的交给参考缓冲，从获准接缝生效 |
| ⑥ 控制 | 参考窗口中的未来关节位置、速度和相对根朝向；实测关节、机身状态及上一动作的历史 | SONIC 编码器产出 64 维表示，解码器产出 29 维关节动作；PD 和限幅算力矩，每 20 ms 更新一次 |
| ⑦ 物理与证据 | MuJoCo 接收控制力矩 | 实测身体状态回到 SONIC 和本地编排；实测轨迹和运行事件用于独立评分及视频回放，回放画面来自实测轨迹 |

协议类型名已对源码行号核对：`MotionIntent` 在 `src/homebody/intent/contracts.py:201`，`IntentPatch` 在 `:238`，`GenerationRequest` 在 `:324`。〔E1〕

**在线编辑如何生效。** 编排在旧修订继续执行时后台计算新参考；候选按时通过才发布，到接缝后才被控制器消费，实际掌位还要从仿真观测确认。核对一次在线编辑依次看四步：接纳修改 → 候选发布 → 控制器首帧消费 → 实测掌位达标。〔E3〕

例：旧目标是左掌与左肩等高，用户说「左手再高 7 厘米，右手也抬到肩高」。语义层给出一个混合修改，本地编排解析成左掌相对左肩 **+7 cm**、右掌相对右肩 **0 cm**，其余目标和动作描述保留。当前是生成任务时，用旧参考历史请求 ARDY 生成接缝后的续窗；候选迟到或被拒绝，原参考继续执行，耗尽时走缓冲保护。〔E3〕这种「只对列出的既有目标按增量改，其他目标取绝对值」的写法对应 `IntentPatch` 的 `offset_goal_ids` 字段（`src/homebody/intent/contracts.py:251`）。〔E1〕

架构图在现场 `runs/architecture-20261118/`：`frozen-main.svg`（主线）、`sonic-interface.svg`（分支七层）、`online-edit.svg`（在线编辑时序），各带 `.mmd` 源文件；未上传。
