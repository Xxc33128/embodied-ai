# 2026-11-09 ~ 11-15 Qwen 换脑与 HALO 调研

三条线并行的执行周：HomeBody 的换脑对照与 VLM×SONIC 实验分支、Apple HALO 的代码调研与复现规划、以及"大模型指导具身"专题的链接核对。本目录各文档于 **2026-11-23** 补录入库，整理时只做脱敏与归位，未重跑任何评测。

## 本周目标

- HomeBody：在评测框架、技能、场景、评分全部不变的前提下，把决策模型从 DeepSeek API 换成本地部署的 Qwen3.8-27B，量化"国产模型换脑"的代价与收益；同时在实验分支上推进 VLM×SONIC 的开放生成与在线编辑。
- HALO：读完 Apple HALO 官方代码，给出架构、复现门槛与资源规划，为后续复现排期。
- 专题：整理"大模型指导具身模型／直接控制机器人"的公开条目，并核对各条目里大模型在控制回路中的位置。
