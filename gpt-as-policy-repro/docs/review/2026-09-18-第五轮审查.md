## 红

**R1（红）W6 数值对比不具证据力：两侧噪声不同源、未固定，实测差异与纯采样噪声不可区分。**
- 上游证据：JAX `Policy.infer(obs, *, noise=None)` 未传 noise 时由 `self._rng=jax.random.key(0)` split出新 key（policy.py L65/L75），`models/pi0.py` L230-231 `jax.random.normal` 现采样；torch 侧 `pi0_pytorch.py` L380-382 `sample_noise`=`torch.normal`（全局 RNG 无种子）。`w6_jax_ref.py` 与 pi05_service 均未传 noise —— 两次前向是两个独立随机样本。
- 实测（同输入 rng(20260917) 重复调 NPU 服务 7 次）：输出 sha256 逐次全不同；5 次输出 per-dim 均值两两 |diff| **mean=0.0410 / median=0.0234 / max=0.2180 rad，纯噪声带完全覆盖并超过 W6 报告的 0.0193/0.0525**；对新调与已录基线比 mean=0.0356 / max=0.2528。
- 结论：报告 "mean_absdiff=0.0193 → 功能等价" 与 "差异来源=NPU 降精度算子" 均无依据（0.0193 与采样噪声同量级甚至更低）；冻结带 (0.02/0.06) 落在噪声带内，该门槛对转换误差既不灵敏也不特异。连带失效：`w6_reference_inference.py` 的 "确定性前向→固定输出指纹" 及 **W7 基准 sha256 设计**（该指纹永不复现）。

**R2（红）"先冻结后判定"声明不可证，库内证据指向先测后冻。**
- 全 git 历史 grep：0.02/0.06 门槛数字只出现在 af7c31d（与实测数字同一 commit、同日 09:11）；无任何在先 artifact。门槛 0.0193→0.02、0.0525→0.06 呈典型"贴实测取整"形态。
- 冻结判据写 "中位 ≤0.02"，报告引用实测却是 mean=0.0193（median 实算 0.0167，未翻转结论，但口径错位——引用了未冻结的统计量）。计划 §6.3 原文不在库，预注册要求无法核对；按库内证据如实评估：纪律声明不成立/不可验证。
