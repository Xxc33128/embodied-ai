## 2. 发现（按严重度）

### P2-1 预注册 comparisons[1] 的"逐张量中间量 + 未解码动作"对比未兑现

- `configs/validation.json:21` 明文承诺 jax_cpu vs torch_cpu 比较对象为"**逐张量中间量 + 未解码动作 + 解码动作**"；`:24` evidence_required 第 2 条要求"JAX 与 Torch 的中间量（未解码动作）对比记录"。
- 实况：三腿 npz 均为 `(8,10,7)` 解码后动作（output_transform 已做去归一化+[..., :7] 切片）。无 prefix KV、无每步 v_t/x_t、无未解码 32 维输出的任何对比记录。
- 影响：JAX↔Torch 运行时差只在解码终点被约束。解码链（10 步 Euler + 反归一化 + 7 维切片）理论上可压缩/掩盖中间发散（补偿误差不被排除）。实测 max_abs≤0.0135 仍是直接证据，但**"按预注册完成了正式运行"这句话在此项上为假**。
- 定级 P2：显著缺口；不推翻已测数值，但验收声明超出实际执行的协议。

### P2-2 预注册结构性检查（符号一致率、余弦）未执行

- `validation.json:17` 预注册"每 draw 输出与 torch_cpu 参考的逐维符号一致率 >= 0.9，成对余弦 >= 0.99"。
- 实况：`lp_a0_compare.py` 只实现 max/mean 两项；evidence.json 中无 sign/cosine/structural 任何字段（本次程序化检索确认）。此检查是每 draw 一次的两个标量，成本近零却被遗漏——属实现遗漏而非能力限制。
- 定级 P2：预注册要求未完全兑现；因阈值门本身以更大余量通过（符号翻转与低余弦在 max_abs≤0.014 下几乎不可能出现），不推翻结论，但 evidence 与预注册的映射不完整。

### P2-3 evidence_required 记录要素缺位（W7 记录纪律未闭合）

- `validation.json:24` 要求"每 draw 的 **noise/observation sha256**、**checkpoint ID**、三腿输出数组、逐对差值统计"。
- 已兑现：三腿输出数组（服务器 npz）、逐对差值统计（evidence）。
- 缺位：①observation sha256 **任何地方都没有**（真实帧 lp_a0_frames.npz 存在但无哈希入档；合成观测甚至未落盘，只能靠代码+numpy 流重建）；②checkpoint ID 未写入 evidence（脚本只硬编码路径；权重身份本次靠我重新 md5 对账 LP2 记录才闭合）；③noise sha 未记录（数组本身在 noise.npz，可事后计算，但 evidence 未引用）。
- 附带：lock `lp_a0.formal_run.evidence` 描述为"逐 draw 三腿 sha256 + 差值"——**in-repo evidence 文件里并没有 sha256**（sha 只在服务器的三个 meta 文件中，lock 未引用、未入库）。若服务器 data/ 丢失，sha 链即失。
- 定级 P2：fixture 身份目前只能靠服务器留存文件 + 本次审查的重算维持，不入库则不可审计。

### P2-4 输入域代表性：外推范围必须限定

- 6 个真实帧全部来自 libero_goal **单一 suite 单一 task0**（`lp_a0_capture_frames.py:21-27`），且为 set_init_state 后固定 3 步 `[0,0,0,0,0,0,-1]` 的近似初态帧——图像统计、关节位形、prompt（8 个 draw 硬编码同一条 "open the middle drawer of the cabinet"）高度同质；2 个合成 draw 是均匀随机像素（SigLIP 分布外，沿用上轮 P2-1 定性）。
- 无不同 token 长度、无其他 suite、无操作中途（非近初态）观测、无真实腕部遮挡模式。
- 定级 P2：较上轮 n=1 是实质改善，"权重+kernel 栈在被测输入域内数值等价"成立；但 lock/commit 的"runtime numeric equivalence"泛化表述应限定为"在 8-draw 受试输入域内"。跨任务/prompt 长度/图像分布的 kernel 行为差异（尤其 attention 路径）未被采样。

## 4. 结论与最小补齐路径

**判定：formal PASS 可维持（限定口径）**——"8 draws × 三腿在预注册 per_draw 阈值内 8/8 通过"这一命题经位级复核为真且证据链闭合；但验收声明原文"按预注册的 validation.json 完成了正式运行"不成立，因预注册协议的中间量/未解码动作对比（P2-1）、结构性检查（P2-2）、W7 记录要素（P2-3）未兑现。建议：

1. lock `lp_a0.status` 追加限定："PASS (formal: preregistered per_draw threshold gate 8/8; intermediate-tensor/undecoded-action comparison and structural checks NOT executed — open)"，并把 `formal_run.evidence` 描述改为与文件实际内容一致（差值 only；sha 在服务器 meta）。

3. 若要完整兑现预注册：JAX/Torch 各加一次带中间量钩子的单 draw 前向（未解码 32 维 + 抽样 KV/v_t），存档对比记录。
