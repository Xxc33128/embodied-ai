## 二、发现清单（按严重度）

### P1-1　`pi05_libero_pt` 缺 `assets/`（norm_stats），官方 PyTorch 加载路径会静默拿不到归一化统计

- 证据（产物）：`ls /data_nv0/gpt-as-policy-repro/data/checkpoints/pi05_libero_pt/` 仅有 `config.json` + `model.safetensors`；而 JAX 源侧存在 `pi05_libero/assets/physical-intelligence/libero/norm_stats.json`（state mean/std 等）。
- 证据（根因）：官方转换脚本 `examples/convert_jax_model_to_pytorch.py:536-541` 的 assets 复制条件是 `pathlib.Path(checkpoint_dir).parent / "assets"`，即期望 `/workspace/data/checkpoints/assets`；本布局（GCS 镜像）assets 在 **checkpoint 目录内部**（`pi05_libero/assets/...`）→ `assets_source.exists()` 为 False → **静默跳过，无任何日志**。
- 证据（后果链）：openpi 官方 PyTorch 推理入口 `src/openpi/policies/policy_config.py:48-66`——检测到 `model.safetensors` 即走 PyTorch 分支；若调用方不显式传 `norm_stats`，则 `load_norm_stats(checkpoint_dir/"assets", asset_id)`（`src/openpi/training/checkpoints.py:110-114`）在 `pi05_libero_pt/assets` 不存在时返回 None → `transforms.Normalize(None, ...)` 进入 input/output 变换链，状态/动作不按官方统计归一化（或直接报错）。**这会直接使后续数值验收与评测失效。**
- 修复（一行，建议立即执行）：
  ```
  cp -r /data_nv0/gpt-as-policy-repro/data/checkpoints/pi05_libero/assets /data_nv0/gpt-as-policy-repro/data/checkpoints/pi05_libero_pt/assets
  ```
  或在接线时显式传 norm_stats/指向 JAX 目录 assets。注意本地 repro `src/`、`scripts/` 目前**零处引用 `pi05_libero_pt`**，接线时尚未固化——正是埋雷窗口。

### P2-1　safetensors 内含一张 526.6MB 的随机初始化死重张量（`gemma_expert.lm_head.weight`），并证明 `strict=False` 静默通道真实存在

- 证据（审计实测）：映射字典 811 张量中无此键；文件中该键 shape=(257152, 1024)、BF16、min/max=±0.11279、std=0.0199998 —— 与 HF Gemma `_init_weights` 的 `initializer_range=0.02` 正态初始化吻合（±5.6σ 极值），绝非 JAX 权重。
- 证据（来源）：`gemma_pytorch.py:57-58` —— `self.gemma_expert = GemmaForCausalLM(config=...)` 自带随机 `lm_head`，仅 `embed_tokens` 被置 None 与 PaliGemma 共享；`pi0_pytorch.py:520`（convert 脚本行号 520）`load_state_dict(all_params, strict=False)` **返回值被丢弃**，missing/unexpected keys 完全静默。
- 数值影响：**无**。动作前向只用 `gemma_expert.model`（base model，`gemma_pytorch.py:130,145`）与 `action_out_proj`（`pi0_pytorch.py:369-372,462`），`lm_head` 不参与 π₀.₅ 动作推理；PaliGemma 侧 `lm_head` 虽在 `modeling_paligemma.py:502` 被其自身 forward 使用，但 policy 路径只调 `language_model.forward`，且它 tie 到 embedder（值=JAX 权重）。
- 工程影响：(a) 该张量使 `model.safetensors` 的 **md5 不可复现**（重跑转换随机初始化不同，哈希必然漂移——lock 记录哈希时必须注明）；(b) 占文件 7.3%（526,647,296 B / 7,233,650,408 B），任何"与参考转换逐张量对比"的验收若不含此键差异说明都会误报。官方脚本原样行为，不阻塞验收，但必须写进 lock 注记。
