平均每轮耗时与统计口径

平均值以全部已完成决策为分母，包括被拒绝的决策；拒绝时执行步数为 0。π 推理含设备同步；π 传输项是文件交换、排队与序列化耗时。GPT round trip 包含网络、排队、推理与用量事件返回，现有接口不能将纯网络与服务端推理拆开。渲染为 sim.render（含像素读回）；物理为 mj_step。环境其他工作以 env.step 扣除前两项计算，各项不重复相加。

每轮用量与延迟

GPT 请求总耗时覆盖推理、网络、排队及用量收尾，不是服务端纯推理时间（接口未提供）。Decode 为首个至最后可见 JSON 分片的客户端间隔，含缓冲/通信，不是纯解码内核时间。TTFT 与 Decode 已包含在 GPT 总耗时内，不能重复相加。点击任意行查看完整决策。TTFT = 发起请求至客户端收到首个可见 JSON 分片。TPOT 估算 =（末分片时间 − 首分片时间）÷（输出 Token − reasoning Token − 1），分片不等于单 Token，因此不能视作服务端精确 TPOT。若接口重发输出，TTFT 与 TPOT 估算包含重发等待；废弃分片另存于完整流记录，不拼入执行 JSON。reasoning Token 仅展示接口计数，公开理由与 assessment 展示模型输出文本。纯 π 连续动作不适用文本 TTFT/TPOT。
