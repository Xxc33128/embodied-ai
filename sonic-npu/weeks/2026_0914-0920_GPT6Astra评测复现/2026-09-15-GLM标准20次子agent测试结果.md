## 执行方式

- 依据《2026-09-15-bowl标准测试流程.md》与 `bowl-eval-v1/`：20 调用 / 900 步 / effort=medium（请求值）/ max_speed_frac=0.25 / image_horizon=2，任务句与系统/接口提示词 SHA256 与 protocol.json 一致。
- 每 trial 一个全新无历史子 agent 连续完成整 trial（persistent-subagent 接入组，与 GPT persistent 批次同组定义；已披露与"每决策新建上下文"独立 API 条件的差异）。
- 与 GPT 批次共享同一冻结初态库（seeds 2000–2019，diff 逐文件一致），具备后续按 seed 配对比较条件。
- 调度披露：最多 6 trial 并发（推理等待期物理暂停、环境互相隔离、初态逐 trial 核对），**墙钟不作串行比较**（均值 2179s/trial 仅供参考）。

## 值得记录的现象（E2）

1. **模型信念 vs 物理**：trial-14 模型自称腕镜确认方块已入碗并以 done 收尾，物理轨迹显示全程未接触方块（stage 0）；trial-03 自称入碗压坐，实际弹到碗外（stage 3）。盲评剥离 notes 的流程有效防止文字带偏。
2. **执行时序怪癖的模型侧利用**：多个 trial 独立发现"位置型 move_to 仅 2-4 步、夹爪行程型调用 39-80 步"，并用中间夹爪目标（0.5/0.6）延长插值窗口——即 SOP §4 预先披露的"重复指定 gripper 改变 chunk 长度"行为，协议内、全模型同工具。
3. **夹取是主瓶颈**：11 个 trial 连稳定接触都没有（腕相机斜装 + eef 参考高于指垫 → 1-3cm 系统性对中偏差）；stage≥2 的 3 个 trial 均靠多次重试闭合。
4. **预算行为**：调用均值 18.5/20（12 次 give_up、5 次 done、3 次步数耗尽）；trial-11 持物悬于碗口上方时调用耗尽，差一次松爪。
