# Part B：P2 ARM_ONLY 全身迁移实验

## 10. P2 核心问题

P1 已经证明右肘单变量在完整 `dance_9` 中有效。P2 要回答：

> 在保留右肘 `0.01` 的基础上，把其余 13 个手臂关节 armature 也对齐到 Isaac runtime 的 `0.01`，是否进一步降低手臂轨迹误差，同时保持 root、全身和 body/anchor 指标在保护范围内？

P2 检验的是 **相对 elbow-only 的增量效应**。主指标不能把已经由 P1 证明的右肘改善再次计入新增收益。

## 11. 实验条件

| 条件 | 引擎 | 模型 | 运行次数 | 处理 |
|---|---|---|---:|---|
| A `ISAAC-REF` | Isaac/PhysX | 冻结 full-body | 复用 1×10s | 不启动 Kit |
| B `MJ-NATIVE` | MuJoCo | 29 关节 native | 复用 P1 R1–R3 | 不重跑 |
| C `MJ-ELBOW-ONLY` | MuJoCo | 只匹配右肘 | 复用 P1 R1–R3 | P2 的直接对照 |
| D `MJ-ARM-ONLY` | MuJoCo | 14 个手臂关节匹配 | 新增 smoke + R1–R3 | 本轮唯一新条件 |

总分析输入为 10 条正式 trace：A×1、B×3、C×3、D×3。新增仿真只有 D 的 1 次 smoke 和 3 次正式运行。

原始 MuJoCo 与 P2 值：

| 关节类别 | 数量 | native armature | P2 armature |
|---|---:|---:|---:|
| shoulder pitch/roll | 4 | `0.0685` | `0.01` |
| arm yaw | 2 | `0.0685` | `0.01` |
| elbow pitch | 2 | `0.0685` | `0.01` |
| elbow yaw | 2 | `0.03` | `0.01` |
| wrist pitch/roll | 4 | `0.03` | `0.01` |

P1 的 `right_elbow_pitch_joint` 在 C 和 D 中均为 `0.01`。因此 D 相对 C 实际新增 13 个 armature 修改。

禁止修改：

- 腰、腿、neck 等其余 15 个关节；
- default class；
- damping、frictionloss、Kp/Kd；
- actuator gear、ctrlrange、forcerange；
- body mass/inertia/COM、geom 和 contact；
- timestep、solver、iterations、tolerance；
- policy、motion、canonical、history、delay 和 gain。

## 13. 预注册指标与阈值

### 13.1 主效应

主集合：`ARM_INCREMENTAL_13`，即上面 14 个关节去掉 `right_elbow_pitch_joint`。

主窗口：`0–2 s`，与 P1 保持一致。

对每个条件和 repeat：

```text
joint_rmse_j = RMSE_t(q_mujoco_j - q_isaac_j), t in [0, 2s]
E13 = mean(joint_rmse_j for j in ARM_INCREMENTAL_13)
absolute_improvement = E13_elbow_only - E13_arm_only
relative_improvement = absolute_improvement / E13_elbow_only
```

`arm_group_effect_pass` 同时满足：

```text
每次 repeat relative_improvement >= 10%
每次 repeat absolute_improvement >= 1e-3 rad
3/3 repeat 改善方向一致
13 个新增关节中至少 8 个 joint_rmse 改善
13 个新增关节的 per-joint improvement 中位数 > 0
```

### 13.2 右肘保持条件

D 相对 C 的右肘 0–2 秒 MAE 增量：

```text
<= max(C 的 10%, 1e-3 rad)
```

### 13.3 系统保护条件

D 相对 C 每个 repeat 同时满足：

```text
不更早触发 failure predicate
root height RMSE 增量 <= max(C 的 10%, 0.002 m)
root roll RMSE 增量   <= max(C 的 10%, 0.005 rad)
root pitch RMSE 增量  <= max(C 的 10%, 0.005 rad)
29 关节 mean q RMSE 恶化 <= 10%
14-body position RMSE 增量 <= max(C 的 10%, 0.010 m)
pelvis anchor position RMSE 增量 <= max(C 的 10%, 0.010 m)
14-body quaternion angle RMSE 增量 <= max(C 的 10%, 0.010 rad)
右肘保持条件通过
```

### 13.4 辅助指标

辅助指标不改变主 gate：

- 0–10 秒 E13 和 E14；
- left arm 7 关节、right arm 7 关节分组；
- shoulder / elbow / wrist 分组；
- 每关节 `q_des`、`q_des-q`、action；
- 每关节 active 1 秒窗口；
- arm torque RMS/peak/saturation；
- root x/y drift、contact 和 fall reason。

每关节 active window 只从冻结 Isaac `q_des` 计算，并在加载 D trace 前保存 `active_windows_13.json`。

## 25. 本轮停止条件

## 26. 完成后如何选下一步

### `SUPPORTED_ARM_GROUP_TRANSFER`

编写并执行 `WAIST_ONLY` 单变量分组计划。沿用 A/B、当前最佳条件和 waist-matched 条件，不直接进入 17 关节全改。

### `ARM_GROUP_EFFECT_WITH_SYSTEM_TRADEOFF`

先做离线闭环传播分析：

```text
arm q 变化
  → observation 变化
  → action/q_des 分叉
  → root/body/anchor 变化
```

没有明确传播路径前暂停扩大修改范围。

### `NO_INCREMENTAL_ARM_GROUP_EFFECT`

保留 P1 elbow-only 作为当前最小有效修改，停止扩展手臂关节；优先执行原计划剩余的 Lab `0/20 ms` 延迟实验。

### `INVALID_P2`

只修输入、资产、日志、哈希或分析门禁。有效性恢复后重跑受影响条件。
