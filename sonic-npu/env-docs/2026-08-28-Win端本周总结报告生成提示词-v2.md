### 一、任务目标和边界

本周最初任务始终是回答以下问题：

1. Humanoid Lab、Humanoid Gym、SONIC 分别怎样实现 Sim2Sim；策略从训练侧进入目标引擎时经过哪些 observation、history、action mapping、PD、资产和时序环节。
2. 三个项目目前分别具有哪些可复核的 Sim2Sim 证据，哪些只有单引擎或历史证据。
3. Humanoid Lab 的同策略 Isaac/PhysX–MuJoCo `dance_9` 基线表现有何差异。
4. 单关节隔离实验能否识别某个物理因素；本周对 `right_elbow_pitch_joint` 的 armature 结论能够支持到什么范围。
5. 本周形成了哪些可迁移到 SONIC 的 Sim2Sim 方法和经验。

不要把本周报告写成 N5-R2 调试流水账。armature 是用于回答“怎样形成有效物理层因果证据”的一条支线，不能替代三项目实现比较、Lab 基线视频/曲线、Gym 参考结果和 SONIC 经验总结。

### 五、证据冲突时的优先级

任何数字或结论出现冲突时，按以下顺序处理：

1. **可加载的原始 trace + 与之绑定的真实 runner/model/canonical hash**；必要时从 trace 复算。
2. **同一 run 的 manifest、initial-state readback 和 stdout**。
3. **可由包内原始证据重新生成的 G0/G6/gate/summary**。
4. **实际可见的视频、首中尾帧和图表**。
5. **日期最新的审查文档**。
6. **README、旧报告、旧 gate、聊天口述**。

低优先级材料不得覆盖高优先级证据。若不能消解冲突，在报告中明确列出“证据冲突/待归档”，不要任选一个看起来更好的数字。

特别检查以下已知风险；这些是核查项，不是让你直接照抄的结论：

- `04_isolation_N5R2` 是否真的包含 18 条 NPZ/manifest/log，而不是只有 6 个 JSON 摘要。
- `elbow_gates.json`、`hip_gates.json` 是否与各自 G6 一致，且 `validity=true`、`all_pass=true`；不得手工改 JSON。
- N5-R2 的 R1 是否是当前 runner 生成的真实 R1，不能把旧 `04_isolation_smoke` 混作 R1。
- Isaac 10 s 视频是否能看到完整机器人；“非黑帧”不等于“可作为行为证据”。
- `sonic_II_IM_MM_MI_ledger.csv` 引用的文件是否真实存在；不存在就写 unavailable。
- 根 `SHA256.txt` 和嵌套 `code_B1_patch\SHA256.txt` 是否都与最终文件一致；若只保留一个根清单，要在 README 说明。
- Isaac trace 如果没有 torque 字段，`torque_10s.png` 只能标为 MuJoCo torque，不能写成双引擎 torque 对比。
- 完全一致的三重复证明的是本设置下的执行确定性，不等于跨随机种子或统计泛化。

### 六、允许形成的主要结论口径

在证据核查通过的前提下，可以使用以下有边界的表述：

1. Lab：同一 ONNX、canonical contract 和统一策略周期下，Isaac/PhysX 与 MuJoCo 的 `dance_9` 10 s 均跑满；报告 root、q/q_des 等实际复算差异，并展示配对视频/曲线。不要写“物理完全对齐”。
2. 隔离实验：仅在固定的 right-elbow 单关节、无接触、0.1 rad 阶跃和冻结 PD 设置下，将 MuJoCo armature 从 native 对齐到 Isaac 后，MAE 约从 `0.006752` 降至 `0.001704 rad`，改善约 `74.8%`；t50 从约 `0.17743 s` 接近 Isaac 的 `0.16382 s`，matched 约 `0.16329 s`。只有在最终 gate 和 18 条原始证据同步后才能写成闭环结果。
3. hip 是负对照：native/matched armature 相同，输出差为 0；相对 Isaac 的 MAE 约 `0.000494 rad`。这支持实验能区分“真实干预”和“无操作”，但不外推到全身动作。
4. Gym：本周提供的是 MuJoCo 单引擎 100 Hz 参考基线和历史视频，不是本机 Isaac Gym–MuJoCo 成对对比；无统一 failure predicate 时不要仅凭 runner 跑满写“严格不跌倒”。
5. SONIC：官方源域可运行、动作空间映射修复是跨引擎迁移的必要条件；目标域微调和回迁现象提示存在物理/闭环引擎绑定候选，但没有隔离实验时不能宣称唯一因果。

如果实际核查结果不满足上述前提，按真实证据降低结论强度。
